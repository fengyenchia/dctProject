# 音虫 VR｜待確認與驗證清單

日期：2026-11-03｜版本：VR v0.1

本清單集中列出需組員決定與原型驗證的事項。已採用 PCVR 與 VR 控制器操作虛擬捕捉器／回收站，不再列為討論選項。

## 1. 先決定的設備與互動

- [ ] 可借用哪些相容 PCVR 的頭戴裝置、控制器及電腦？設備原有追蹤是否需基地台？確認實際執行環境後鎖定 Unity／套件版本。
- [ ] 體驗採站姿或坐姿？移動採傳送／分段轉向，或允許搖桿連續移動？測試眩暈、理解程度與手部操作衝突。

## 2. 任務、捕捉與聲音

- [ ] 任務達成條件、SAN 初始／扣值、一場體驗時間，以及正式城市範圍、群落數與同時顯示上限？
- [ ] 持續瞄準捕捉時間（原先考慮 2～5 秒）、捕捉距離、判定範圍、細微手抖容許值及進度提示？
- [ ] 觀眾為何自然發聲、如何引導？音量／持續時間如何對應擾動，是否影響捕捉難度？
- [ ] 捕捉噪音促成新群落的時機、數量、出現區與種類？如何讓觀眾注意到「捕捉又造成誕生」？
- [ ] 頭戴麥克風在選定 PCVR 連線下能否被 Unity 讀取？測試耳機漏音、工作人員說話及鄰攤聲音誤判；定出門檻及播放抑制策略。
- [ ] 捕捉與擾動回饋是否清楚、噪音播放是否仍舒適可接受？不以提高實際音量作為唯一表現。

## 3. 回收與紀念品

- [ ] 感應範圍與到站提示怎麼設計，確認鍵映射哪顆控制器按鍵？兩步操作能否在不口頭教學下完成？
- [ ] 種類／群落數量對應哪些物品、如何修復城市？轉化、修復演出與引導視角如何安排？
- [ ] 各種類聲部的實際音色與素材？重複收集是否影響旋律編排？
- [ ] 成果 QR 顯示於離場螢幕、工作人員管理畫面或其他位置？如何確保觀眾取下頭戴後拿到自己的成果？
- [ ] 線上服務預算、保存政策與展後維護分工？是否使用實體列印？

## 4. 美術、效能與展場

- [ ] 城市美術風格與場景規模；原投影素材哪些可改為 3D／貼圖，哪些需重製？捕捉器是否沿用原概念外型及像素 UI？
- [ ] 捕捉器是否提供雷達、收藏總覽及音虫詳細卡片？雷達要呈現哪些虛擬群落資訊，如何安排頁面切換而不與移動、確認操作衝突？
- [ ] 選定頭戴設備的刷新率、可接受效能與畫質設定；以實機測量最密集音虫、粒子、回收修復及雙眼畫面效能。
- [ ] 實際可用面積、站位、接待／離場路線、活動邊界及監看方式？原投影配置圖不是 VR 定案圖。
- [ ] PCVR 採有線還是無線？有線測走線、轉身與拉扯；無線測專用網路、遮擋、干擾與持續連線，另估頭戴及控制器續航與輪替。
- [ ] 選定追蹤系統對光照、反光、遮擋及控制器視野的限制；進出邊界、摘下頭戴與追蹤遺失的暫停／恢復能否可靠運作？
- [ ] 可借與需購設備、預算、模組負責人與第一次完整原型日期？清潔、眼鏡配戴、工作人員接待及設備充電的流程？
