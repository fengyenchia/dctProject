### 其他參考

以下為開發參考資料，不代表採購清單。選型與技術討論統一見[待確認與驗證清單](待確認與驗證清單.md)。

#### 紅外線接收與點位識別

- [PAJ7025R3 紅外線定位模組／樣品包](https://www.codico.com/en/paj7025r3-sample-kit-cdc)：廣角紅外線光點感測器與採購資料，依實際套件內容使用。
- [PAJ7025R3 原廠資料表（PDF）](https://www.codico.com/media/productattach/p/i/pixart_paj7025r3_-_productbrief_2461050_4.pdf)：SPI、電壓、光點輸出及取樣設定；點位閃爍編碼由本案韌體解讀，識別固定點而非種類；同點可再出現不同種類。投影音虫不隨識別編碼閃爍。
- [OpenFIRE ESP32 專案](https://github.com/alessandro-satanassi/OpenFIRE-Firmware-ESP32)：PAJ7025R3 驅動、追蹤與無線的實作參考；相機可偵測多光點，本案點位身分識別由自製韌體處理，不直接採用四點整牆定位。
- [PixArt 追蹤實作與 PCB 參考](https://github.com/trzy/PixArt)：以 PAJ7025R2 為主，可參考接線與主機端運算；不是 R3＋ESP32-S3 可直接套用的完整方案。

#### 紅外線發射燈與時序控制

- [Vishay 紅外線發射 LED 選型](https://www.vishay.com/en/ir-emitting-diodes/)：比較波長、發光角度與電流，配合接收模組及斜拍需求選型。
- [TI TLC59282 LED 驅動器](https://www.ti.com/product/TLC59282)：多點燈具開關與定電流驅動資料。
- [ESP32-S3 GPTimer](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/gptimer.html)：硬體計時器與定時控制文件。
- [ESP32-S3 LEDC／PWM](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/ledc.html)：燈光亮度與 PWM 控制；不等於完成點位識別。

#### NFC 回收站

- [DFRobot Gravity NFC 模組 DFR0231-H](https://www.dfrobot.com/product-1917.html)：回收座 NFC 模組資料，以 I²C／UART 連接座端 ESP32。
- [Adafruit PN532 函式庫與讀卡範例](https://learn.adafruit.com/adafruit-pn532-rfid-nfc/arduino-library)：讀取標籤 UID 的實作參考。
- [NXP NTAG213／215／216 標籤](https://www.nxp.com/products/NTAG213_215_216)：捕捉器貼附的被動式 NFC 標籤資料；被動標籤不需捕捉器供電。
- [NXP PN532 產品狀態](https://www.nxp.com/products/rfid-nfc/nfc-hf/nfc-readers/nfc-integrated-solution:PN5321A3HN)：原廠不建議新設計，供查閱產品狀態。
- [NXP PN7160](https://www.nxp.com/products/PN7160)：讀取控制器資料。

準備 2～3 支捕捉器，每場啟用一支；每支的 NFC 標籤對照設備編號。到站資料經讀取器 → 座端 ESP32 → 本機串接服務 → Unity，記錄本場「已感應」。觀眾可移開後再按捕捉器確認按鈕，Unity 檢查已感應、尚未回收及目前可回收，才結算一次；換備機需重新感應。演出由兩面主投影呈現，SAN／收集紀錄保存在主機。

- [ESP32-S3 SPI 驅動](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/spi_master.html)：連接紅外線相機與其他 SPI 裝置。

- [TI DRV2605L 震動驅動器](https://www.ti.com/product/DRV2605L)：震動回饋資料。

#### 通訊、Unity 與必要線上紀念品網頁

- [WebSocket 雙向通訊](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API)：本機串接服務與介面的通訊參考。
- [ESP-NOW 官方文件](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/network/esp_now.html)：裝置間無線通訊參考；連電腦需另設接收及轉接介面。
- [Unity 多顯示器輸出](https://docs.unity3d.com/6000.0/Documentation/Manual/MultiDisplay.html)：兩面主投影的輸出設定。
- [Unity 麥克風輸入](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Microphone.Start.html)：現場收音介面。
- [Unity Audio Mixer](https://docs.unity3d.com/6000.0/Documentation/Manual/AudioMixer.html)：城市聲音與互動音效混音。
- [Next.js 開發文件](https://nextjs.org/docs/app)：必做的手機版線上紀念品、成果 API 與本機管理頁。
- [Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API)：成果頁依音虫種類對應聲部，組合預製音軌並控制播放／暫停。

聲音互動分兩路：觀眾聲音 → 麥克風／音訊介面 → Unity 分析 → 既有音虫擾動；成功捕捉 → Unity 捕捉器噪音事件 → 音響播放／新音虫生成控制。新音虫誕生由同一次捕捉噪音事件驅動；成功捕捉後扣一次 SAN 並震動，呈現精神啃食與器具受衝擊。
