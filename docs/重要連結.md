### 其他參考

以下為開發與選型參考，候選零件仍需確認相容性及實測。

#### 紅外線接收與點位識別

- [PAJ7025R3 紅外線定位模組／樣品包](https://www.codico.com/en/paj7025r3-sample-kit-cdc)：廣角紅外線光點感測器；樣品包不等於附轉接板與 ESP32 的完整套件。
- [PAJ7025R3 原廠資料表（PDF）](https://www.codico.com/media/productattach/p/i/pixart_paj7025r3_-_productbrief_2461050_4.pdf)：SPI、電壓、光點輸出及取樣設定。
- [OpenFIRE ESP32 專案](https://github.com/alessandro-satanassi/OpenFIRE-Firmware-ESP32)：PAJ7025R3 驅動、追蹤與無線的實作參考；音虫點位輪流亮燈的識別需另行整合。
- [PixArt 追蹤實作與 PCB 參考](https://github.com/trzy/PixArt)：以 PAJ7025R2 為主，可參考接線與主機端運算；不是 R3＋ESP32-S3 可直接套用的完整方案。

#### 紅外線發射燈與時序控制

- [Vishay 紅外線發射 LED 選型](https://www.vishay.com/en/ir-emitting-diodes/)：比較波長、發光角度與電流，配合接收模組及斜拍需求選型。
- [TI TLC59282 LED 驅動器](https://www.ti.com/product/TLC59282)：多點燈具開關與定電流驅動的候選，需核對負載及控制時序。
- [ESP32-S3 GPTimer](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/gptimer.html)：規劃輪流亮燈與取樣時段；跨裝置同步仍需另行設計。
- [ESP32-S3 LEDC／PWM](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/ledc.html)：燈光亮度與 PWM 控制；不等於完成點位識別。

#### ESP32-S3、LCD、震動與聲音

- [ESP32-S3-DevKitC-1 官方開發板](https://www.espressif.com/en/products/devkits/esp32-s3-series/esp32-s3-devkitc-1)：板卡、硬體資源與規格。
- [ESP32 Arduino 開發文件](https://docs.espressif.com/projects/arduino-esp32/en/latest/)：韌體入門、函式庫與範例。
- [PlatformIO ESP32-S3 板卡設定](https://docs.platformio.org/en/latest/boards/espressif32/esp32-s3-devkitc-1.html)：編譯、燒錄及除錯；設定須對應實際板卡版本。
- [ESP32-S3 SPI 驅動](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/spi_master.html)：連接紅外線相機與其他 SPI 裝置。
- [ESP32-S3 SPI LCD](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/lcd/spi_lcd.html)：LCD 連接與畫面更新。
- [LVGL 介面函式庫](https://lvgl.io/docs/open)：製作 SAN 量條、文字及裝置狀態介面的候選。
- [TI DRV2605L 震動驅動器](https://www.ti.com/product/DRV2605L)：震動回饋的候選，需搭配相容馬達。
- [ESP32-S3 I²S 音訊](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/i2s.html)：搭配音訊模組／功放播放裝置音效。
- [ESP32-S3 硬體設計與供電檢查](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/schematic-checklist.html)：供電、接腳及電路規劃；電池與充電模組另行選型。

#### 通訊、Unity 與成果網頁

- [WebSocket 雙向通訊](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API)：本機串接服務與介面的通訊參考。
- [ESP-NOW 官方文件](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/network/esp_now.html)：裝置間無線通訊的候選；連電腦需另設接收及轉接介面。
- [Unity 多顯示器輸出](https://docs.unity3d.com/6000.0/Documentation/Manual/MultiDisplay.html)：兩面主投影的輸出設定。
- [Unity 麥克風輸入](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Microphone.Start.html)：現場收音介面。
- [Unity Audio Mixer](https://docs.unity3d.com/6000.0/Documentation/Manual/AudioMixer.html)：城市聲音與互動音效混音。
- [Next.js 開發文件](https://nextjs.org/docs/app)：管理頁、離場成果頁與 API。

#### 聲音與其他定位備案

- [VIVE Tracker 3.0](https://www.vive.com/tw/accessory/vive-tracker/)：外部空間追蹤備案。
