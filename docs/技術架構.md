# 音虫互動投影技術架構

日期：2026-10-30  
版本：v0.9  
用途：供組員了解作品運作方式、軟硬體需求與跨組配合事項。

程式介面、資料格式與詳細驗收見[開發規格](開發規格.md)。主要方案為自製無線紅外線捕捉器；近距離定位、雙牆自動切換及續航均須經原型驗證。

## 1. 專案概述與功能範圍

本作品為單人進場的城市互動投影。觀眾在接待區觀看前導、領取捕捉器，聆聽城市聲音、發聲吸引音虫，再對準投影中的音虫按下捕捉。

觀眾可自由走動、轉向兩面牆。捕捉器以廣角紅外線相機取得瞄準位置，Unity 判斷是否捕捉成功。音虫可微微移動、生成或消失；定位用的紅外線參考點固定在牆面周圍。

捕捉器的 LCD 顯示 SAN 與操作狀態，成功時提供震動與聲音。SAN 依成功捕捉數量降低，達限制就停止捕捉、引導前往回收站。到站確認後才能回收，完成轉化與城市修復，再取得感謝信、個人旋律及選配列印紀念品。

## 2. 系統連接架構

```text
牆面紅外線參考點 → 捕捉器紅外線相機
自製捕捉器：ESP32-S3
  ├─ 輸入：瞄準資料、捕捉按鈕
  └─ 回饋：LCD／震動／聲音
            ↕ 展場 Wi-Fi，即時雙向通訊
展場電腦：本機串接服務（Gateway） ↔ Unity
  ├─ Gateway：裝置連線、場次、成果同步與列印
  └─ Unity：捕捉判定、音虫、SAN、雙牆投影及聲音

現場麥克風 → 音訊介面 → Unity
回收座接點／感應訊號 → 本機串接服務 → Unity
Unity → 兩面主投影／回收站演出／喇叭
本機串接服務 → 印表機（選配）
本機成果 → 雲端成果服務 → 觀眾手機查看
```

**Unity 統一決定遊戲結果。**例如：對準音虫並按下捕捉 → 傳送瞄準位置 → Unity 確認成功 → 投影音虫消失、LCD 更新 SAN，裝置震動及發聲。

本機串接服務（Gateway）是執行於展場電腦的程式，負責連接捕捉器與 Unity，處理場次、成果同步及列印。即時遊戲在展場內運作；雲端保存離場後可開啟的成果，外網中斷不應阻塞現場捕捉。

每場只綁定一台捕捉器。結尾先保存成果，裝置與場景重置完成後才開放下一場。

## 3. 主要開發軟體

| 軟體／技術 | 用途 |
| --- | --- |
| Unity、C# | 城市、音虫、捕捉與回收規則、雙投影、現場聲音 |
| ESP-IDF 或 PlatformIO／Arduino C++ | ESP32-S3 韌體、紅外線讀取、按鈕、LCD、震動及聲音 |
| OpenFIRE ESP32 | 紅外線追蹤、校正及廣角修正的程式參考；雙牆識別與作品功能需另外整合 |
| Node.js、WebSocket | 本機串接服務、裝置與 Unity 的即時雙向通訊、成果同步及列印 |
| Next.js | 離場成果頁與資料查詢；本機管理頁供工作人員操作 |
| SQLite／PostgreSQL | 分別保存現場紀錄及雲端成果 |
| Web Audio API | 成果頁播放預製音軌 |
| Blender、音訊剪輯／混音軟體、Git／Git LFS | 模型、動畫、聲音及版本管理 |

物件投影校正可依需求評估 TouchDesigner；複雜聲音處理可評估 Max/MSP 與 OSC。套件版本、追蹤演算法及通訊效能須經原型確認。

## 4. 設備與展場配置

![展場配置原圖](assets/展場配置_2026-10-29.png)

預計於華山展出，依新版展場圖整理，外框預估約 **11.5 × 5 公尺**，非施工比例。上方長牆與左側短牆為 L 形投影；右側為接待區及後台；回收站位於左下出口附近。中央 P1／P2 位置依圖示保留，實際光路、架設高度與遮擋待場勘。參考點數量、固定方式、供電與走線位置須配合場地確認。

| 設備 | 規劃數量 | 用途 |
| --- | --- | --- |
| Windows 主控電腦、獨立顯示卡 | 1 台 | 執行 Unity、Gateway、音訊與多畫面輸出 |
| 主投影機、固定幕面及支架 | 暫定 2 組 | 分別對應兩面牆，驗證覆蓋、亮度與人影遮擋 |
| 無線捕捉器 | 每場 1 台，建議另備 1 台輪替 | ESP32-S3、紅外線相機、LCD、按鈕、震動馬達、喇叭及電源 |
| PAJ7025R3 與相容轉接板 | 每台捕捉器 1 組，候選 | 廣角紅外線光點追蹤；供貨、接線及實際可用視角待驗證 |
| 紅外線參考點、驅動與固定供電 | 依定位配置 | 提供牆面定位依據，數量依覆蓋及雙牆識別測試決定 |
| Wi-Fi 分享器與主機有線網路 | 1 組 | 捕捉器與展場電腦本地通訊 |
| 麥克風／音訊介面／主動式喇叭 | 原型 2 支／1 台／2 支 | 收觀眾聲音、播放城市與互動聲音 |
| 回收座與接點／感應介面 | 1 組 | 確認捕捉器到站；接點或感應型號待原型選定 |
| 充電與備用電源、管理螢幕、線材 | 依配置 | 裝置輪替、維運與接線 |
| 回收站投影／印表機 | 待定／選配 1 台 | 回收演出與實體紀念品，確認能否共用主投影 |

續航先以每台約 **2 小時**為設計目標，非已測結果；以實測功耗決定電池、充電及輪替方式。

## 5. 紅外線定位與捕捉流程

1. **布展校正：**記錄兩面牆的參考點配置，建立裝置瞄準位置與正式投影座標的對應。
2. **開始體驗：**工作人員啟動單人場次並綁定捕捉器，LCD 顯示初始 SAN。
3. **辨識參考點：**紅外線相機取得光點資料，定位程式識別牆面並計算瞄準位置。
4. **提交捕捉：**觀眾按下按鈕，裝置送出有效瞄準資料。
5. **判定與回饋：**Unity 比對音虫當下位置，成功後更新 SAN、收集紀錄及投影，回傳震動與聲音回饋。
6. **自由移動與換牆：**自動切換對應牆面；參考點不足、牆面不明或定位資料過期時，停止接受捕捉，LCD 提示重新對準。

**雙牆自動切換是必要功能，尚待原型驗證。**OpenFIRE 可作為單畫面追蹤的基礎，不能直接視為已完成雙牆辨識；參考點識別、轉角混合光點及切換規則需另外開發。

最近操作距離先測 **0.5／1／1.5 公尺**，記錄靠近、斜拍、移動與轉向時的可用範圍。暗場及減少其他照明有利於控制干擾，但仍需開啟實際投影機測試。

## 6. 聲音、回收與紀念品

| 環節 | 實際運作 |
| --- | --- |
| 聆聽與發聲 | 預製城市聲音引導探索；現場麥克風分析音量與持續時間，驅動音虫反應 |
| 裝置回饋 | LCD 顯示 SAN、定位與連線狀態；Unity 確認捕捉成功後，裝置震動及播放音效 |
| 收音控制 | 實測現場喇叭與捕捉器音效是否誤觸麥克風，設定門檻與反應上限 |
| 回收與修復 | SAN 達限制後引導到站；捕捉器靠近回收座，以接點或感應確認到站，再開放回收操作並播放轉化 |
| 個人旋律 | 依收集種類組合預製音軌，保存配方供成果頁重開播放 |
| 數位與實體成果 | 結尾顯示成果 QR Code，觀眾手機開啟感謝信與旋律；選配列印感謝卡與同一成果連結 |

回收座需確認到站訊號與本場捕捉器的關聯，完成回收後進入結尾。接點或感應只負責到站確認；裝置充電另依電源設計規劃。

## 7. 美術配合與交付需求

| 項目 | 配合重點 |
| --- | --- |
| 場景分層 | 城市、音虫、互動特效及修復動畫分開管理，方便演出與維護 |
| 紅外線參考點 | 預留固定位置、線路及安裝空間，裝飾與觀眾動線避免遮住光點 |
| 雙牆對位 | 交付各牆輸出比例、可捕捉範圍、接縫及座標對應 |
| 音虫 | 定義種類、活動、出現／消失、可捕捉範圍與成功演出 |
| 捕捉器 | 外殼預留相機視野、LCD、按鈕、喇叭及維修空間，避免遮擋天線 |
| 回收座 | 配合感應／接點位置、捕捉器靠近方向及物件投影光路 |
| 聲音與成果 | 城市聲源、音虫音色、操作音效、相同速度與節拍的旋律音軌及紀念品版面 |

交付需包含場景與素材版本、雙牆對位資料、音虫互動定義、LCD 狀態畫面及聲音檔。美術與技術共同確認定位光點可見範圍、投影遮擋與裝置握持。

## 8. 待確認事項與必要測試

| 類別 | 優先確認內容 |
| --- | --- |
| 定位 | PAJ7025R3 供貨與轉接板、0.5／1／1.5 公尺操作、參考點配置、瞄準誤差與光源干擾 |
| 雙牆切換 | 自動識別方式、轉角兩組光點同時入鏡、切換穩定度與失效提示 |
| 場地 | 牆高、實際投影尺寸、最近站位、人影、中央設備光路及回收站投影 |
| 裝置與回收 | 電池續航、充電輪替、LCD／聲音／震動、回收座接點或感應的可靠度 |
| 規則與成果 | SAN 扣值、任務條件、捕捉時間、成果交付、保存期限與列印型號 |
| 通訊與維運 | 本地延遲、斷線恢復、單一控制權、重置、離線成果同步與長時間運作 |

先完成單牆紅外線捕捉，再驗證雙牆自動切換與自由走動；兩項通過後整合聲音、回收及成果。完整測試與分工見[開發規格](開發規格.md)。
