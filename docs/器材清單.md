# 音虫互動投影｜器材清單

查價日期：2026-11-01

原型範圍：**1 支捕捉器、長牆 2 點＋側牆 1 點、1 個 NFC 回收座**。正式捕捉器預計 2～3 支輪替，一次只啟用一支；原型零件可沿用。

型號、用途、價格與來源合併列於下表。價格均為新台幣參考單價，不含運費；多規格商品以選定規格的結帳價格為準。「—」表示未取得可核實的台灣報價，不視為免費，亦未納入總價。
