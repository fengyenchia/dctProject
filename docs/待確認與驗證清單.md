# 音虫互動投影｜必要討論清單

日期：2026-11-01

只列需要組員決定的內容及影響可行性的關鍵測試。架構見[技術架構](技術架構.md)，裝置構想見[捕捉器示意圖](assets/手持掃描器畫面.png)。

## 1. 紅外線捕捉

- [ ] 正式有幾個出現點、最多同時出現幾群音虫？
- [ ] 自動捕捉的確切持續時間為幾秒（先保留 2～5 秒）？
- [ ] **原型測試：**長牆 2 點＋側牆 1 點，在 0.5／1／1.5 公尺、斜掃、轉角及手部晃動時，能否在捕捉時間內正確讀出不同閃爍編碼？並確認群落亂動範圍與對準容許範圍相符。
- [ ] **安裝測試：**幕材是否擋紅外線、燈是否需要外露，以及投影光、現場照明與遮擋是否影響辨識？

## 2. 任務與聲音互動

- [ ] 任務達成條件、SAN 初始值／每次扣值，以及一場體驗時間？
- [ ] 如何引導觀眾發聲？音量／持續時間如何對應既有音虫的擾動程度？
- [ ] 捕捉器噪音促使新音虫誕生：具體生成時機、點位、數量及可出現種類如何設定？
- [ ] **收音測試：**麥克風怎麼擺，才能收到觀眾聲音，並減少喇叭、捕捉器噪音及隔壁展品誤觸發？

## 3. 捕捉器

- [ ] 雷達只是搜尋動畫，還是要顯示音虫實際方向／距離？目前紅外線方案不提供完整周圍地圖。
- [ ] 捕捉器的畫面設計、頁面切換與選單操作如何安排？
- [ ] 除 SAN 與捕捉進度，是否需要收藏總覽、音虫詳細卡片？
- [ ] **板卡驗證：**以 ESP32-4827S043C 為候選，核對尺寸、剩餘接腳及顯示驅動；確認 PAJ7025R3 樣品所需轉接板、供電與訊號電壓，驗證相機、回收按鈕、I²C 震動驅動及 I²S 音效能否同時運作，再定外殼；確認指定主板與相機的台灣供貨。
- [ ] **續航與供電測試：**整機能否達約 2 小時目標？驗證行動電源持續輸出；若改內建電池，確認升壓板輸出電壓與峰值電流符合主板、相機及音效需求，再決定電池、備機與充電輪替。

## 4. 回收與紀念品

- [ ] 回收、轉化與城市修復的具體畫面、音效及演出時長？
- [ ] 各音虫聲部的實際音色、素材與組合效果如何設計？同種類重複捕捉是否影響旋律編排？
- [ ] 成果 QR 顯示在哪裡、停留多久？長期保存所需的服務預算、保存政策及展後維護由誰負責？
- [ ] 是否啟用選配的實體列印？設備／紙材預算為何？

## 5. 場地與執行

- [ ] 依[展場配置圖](assets/展場配置_2026-10-29.png)確認實際尺寸、投影機型號／位置，以及人影是否擋住畫面；是否需要架高或短焦？
- [ ] 紅外線燈、支架、供電與走線如何安裝？場地方允許哪些固定方式？
- [ ] 設備哪些能借、哪些要買？各模組由誰負責，第一次三點原型何時完成？
