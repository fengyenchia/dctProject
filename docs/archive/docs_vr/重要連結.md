## Unity 與 VR

- [Unity OpenXR](https://docs.unity3d.com/Packages/com.unity.xr.openxr@1.14/manual/index.html)：頭戴及控制器接入；選定硬體還需相應執行環境。
- [XR Interaction Toolkit](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@3.1/manual/index.html)：VR 互動框架。
- [Unity 官方 XR 範例](https://github.com/Unity-Technologies/XR-Interaction-Toolkit-Examples)：場景、互動與輸入範例。
- [XR Ray Interactor](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@3.1/manual/xr-ray-interactor.html)：射線、命中及遮擋參考。
- [移動與轉向](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@3.1/manual/locomotion.html)：傳送、移動、XR Origin。
- [控制器震動](https://docs.unity3d.com/Packages/com.unity.xr.interaction.toolkit@3.1/manual/haptic-impulse-player.html)：震動回饋。

以上套件網址是可查閱的 API 參考版本，不表示本專案已鎖定該版本或所有裝置均相容。

## 聲音、通訊與紀念品

- [Unity Microphone](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Microphone.html)：觀眾音量輸入。
- [Unity Audio Mixer](https://docs.unity3d.com/6000.0/Documentation/Manual/AudioMixer.html)：聲音混音及音量分組。
- [WebSocket](https://developer.mozilla.org/en-US/docs/Web/API/WebSockets_API)：Unity、本機服務與管理頁通訊，不傳 VR 影像。
- [Next.js App Router](https://nextjs.org/docs/app)：線上紀念品及成果 API。
- [Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API)：預製聲部同步播放。

觀眾聲音只擾動既有群落；捕捉成功才觸發捕捉器噪音及新群落誕生。線上紀念品保存種類／群落數量、感謝信、修復結果及旋律配方。
