日期：2026-11-08

- 本頁只列團隊待決事項與必要實機測試。
- 遊戲規則見[技術架構](技術架構.md)；功能及[驗收條件](開發規格.md#功能驗收條件)見開發規格，採購查[器材清單](器材清單.md)。

## 1. 影響開發安排的未完成事項

| 事項 | 對開發的影響 |
| --- | --- |
| 相機／主板取得 | 台灣供貨、板版、庫存與交期；未到貨前可先做 Unity／裝置模擬，實體定位及接腳驗證須等零件。 |
| 分工與原型日期 | 確認模組負責人及交付日，影響平行開發與整合安排；不需重新討論已定遊戲規則。 |

## 2. 必要實機測試

P1 先驗證方案能否成立；P2 在完整原型與展場測試。以下尚未完成實測。

| 優先 | 測試項目 | 實測重點 |
| --- | --- | --- |
| P1 | 紅外線定位 | 長牆 2 點＋側牆 1 點；0.5／1／1.5 公尺、斜掃／轉角／手抖、多點編碼／反射與遮擋；<br>分開量測辨識延遲與有效對準時間 |
| P1 | 幕材與光線 | 紅外線穿透／外露安裝、投影光與現場照明、燈光角度；群落活動範圍與可對準範圍一致 |
| P1 | 板卡與供電 | [候選接腳配置](開發規格.md#候選板接腳分配)下，相機 SPI／觸控／震動／Wi-Fi 並行；核對板版、電壓、電池尺寸／保護與充電溫升 |
| P1 | 收音與循聲 | 麥克風位置、音響／鄰攤誤觸、三群聲源的音量、方向及切換；發聲門檻／冷卻調校 |
| P2 | 捕捉與操作 | 原型 3 秒門檻、辨識暗段有效期限、固定點 Mask、切頁／震動對取樣的影響、手部疲勞與提示可讀性；<br>驗證捕捉音量衰減、移開保留及新群原始音量 |
| P2 | 續航與連續接待 | 內建電池約 2 小時目標、備機／充電輪替、NFC 感應／觸控確認、接待教學／重置與清場 |
| P2 | 網路與手機成果 | 現場 Wi-Fi、斷線補傳／重啟保存、免費服務首次喚醒與用量、iOS／Android 掃碼、聲部同步播放與離場重開 |
| P2 | 紙票輸出 | 借用機的 Windows 11 驅動／USB／裁刀、黑白變體辨識、票長／字級／QR 尺寸、連續裁切、缺紙／<br>卡紙／USB 復原、補印與取票動線 |
