## 2. 必要實機測試

P1 先驗證方案能否成立；P2 在完整原型與展場測試。以下尚未完成實測。

| 優先 | 測試項目 | 實測重點 |
| --- | --- | --- |
| P1 | PC 透視支援 | 分別測 Editor 與 Windows 執行檔的透視、外殼疊合、重啟／重置及連續接待；[官方說明](https://developers.meta.com/vr/documentation/unity/unity-passthrough-use-over-link/) |
| P1 | 電腦與 USB Link | 最小程式、頭手輸入／音訊、現有線材與接口、斷線恢復；核對系統／驅動，彩色透視實測傳輸至少 2 Gbps |
| P1 | 收音與循聲 | AEC／VAD 排除自身播放聲；只播放／只發聲／同時播放測試；三群聲源的音量、方向及回應範圍調校 |
| P2 | 外殼對位與活動區 | 手動對位、走動／轉頭／重定位後的穩定性、近距到站與動態 Mask、線材導引；11.5 × 5 公尺為估算 |
| P2 | 效能與連續接待 | 最重場景／雙眼幀率、延遲／顯存、UI／雙螢幕焦點／鏡像、電量／續航／溫升、配戴／清潔與人員協助；<br>驗證捕捉音量衰減、移開保留及新群原始音量 |
| P2 | 網路與手機成果 | 五組共用 Wi-Fi、斷線補傳／重啟保存、免費服務首次喚醒與用量、QR 停留／iOS／Android 掃碼、聲部同步播放與離場重開 |
| P2 | 紙票輸出 | 借用機的 Windows 11 驅動／USB／裁刀、黑白變體辨識、票長／字級／QR 尺寸、連續裁切、缺紙／<br>卡紙／USB 復原、補印與取票動線 |

<details>
<summary>技術組調校參數（展開）</summary>

| 項目 | 原型調校內容 |
| --- | --- |
| 發聲偵測 | 背景音門檻、平滑、最短發聲 0.3～0.5 秒比較、有效停聲與冷卻；涵蓋鄰攤／工作人員聲音 |
| 發聲回應範圍 | 前方角度、距離、遮擋與多群回應上限 |
| 空間音訊 | 先測 [Meta XR Audio SDK](https://developers.meta.com/vr/documentation/unity/meta-xr-audio-sdk-unity/)候選，以頭戴喇叭辨識前後／左右／高度 |
| 空間功能 | 以手動布局／碰撞代理為原型；確有需要再驗證房間模型、持久錨點與深度遮擋的 PC 支援 |

</details>
