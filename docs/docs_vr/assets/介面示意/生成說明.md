# 捕捉器介面示意｜生成說明

日期：2026-11-08

- 用途：VR／MR 虛擬捕捉器的主畫面、收藏分頁及到站回收確認。
- 先以 3 個基礎類型、每類 3 個變體規劃，共 9 個變體；同類保留基礎外形，以配色或局部造形區分。
- 每個變體分別對應不同來源聲音與一個預製聲部。

- 探索／收藏示例：收集 A1、B1、C1、A2，共 4 群，SAN 20；目前正在捕捉 C2。
- 收藏卡片：僅音虫圖像、名稱及來源聲音；只顯示本場已收集變體，不列單卡群數。
- 回收示例：A1、B1、C1、A2、C2，共 3 類、5 個不同變體（5 群），SAN 0；<br>已到站，尚未按確認。
- A／B／C、來源聲音代號與圖樣均為佔位示例；正式名稱、聲音素材及配色依美術與聲音設定製作。
- 慣用手握持捕捉器，另一手控制器以游標與扳機選取介面。

工具：內建 image_gen。畫面為依本方案美術風格製作的像素風概念圖，非 Unity 實機截圖。
