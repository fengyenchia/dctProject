# 音虫 VR｜方案對照與功能覆蓋

日期：2026-11-08｜版本：VR v0.25

此表只作方案比較。各方案的技術架構、開發規格、器材、圖稿及參考資料皆在自身資料夾內；實作不依賴其他方案的檔案或裝置。

## 1. 相同的底層互動規則

| 功能 | 三個方案的共同規則 |
| --- | --- |
| 單人與開場 | 一次一位；管理端建立場次，前導後以字幕與動畫引導操作，發聲步驟僅用字幕 |
| 點位與群落 | 有效出現區中隨機分散生成，全場最多 3 群；每點同時最多一個群落，單隻或一群都算一個捕捉單位 |
| 種類與收集 | 3 類各 3 個變體，共 9 個，均納入隨機池；觀眾任選 5 個不同變體完成，類型可重複；<br>群內可有多個同變體個體 |
| 教學數據 | 觀看字幕／動畫示範即可，發聲僅字幕；展示資料不計入正式 SAN、收藏與成果 |
| 初始探索 | 群落隱藏但存在、持續發聲，先循聲尋找 |
| 循聲與數量 | 全場同時最多 3 群；捕捉 1 群後補 1 群。SAN 歸零停止補充；不另設低音量背景群落。 |
| 發聲顯現 | 目前探索區的既有音虫用 3 秒淡入、再用 1 秒淡出；不需先命中目標，不增加群落 |
| 捕捉進度顯現 | 顯現基準與累積捕捉進度採連續線性對應；移開／換群／中斷都保留進度及對應外觀 |
| 捕捉音量 | 目標聲音隨進度降低；移開／中斷保留對應音量，再對準接續。完成後停聲，新群使用原始音量。 |
| 外觀合成 | max（短暫發聲效果，進度顯現基準）；進度 0 時純發聲後回到隱藏，已有進度只回落至基準 |
| 捕捉回饋與 UI | Unity 統一保存捕捉進度；Mask 呈現方式依各方案的定位與照射方式配置 |
| 自動捕捉 | 不按捕捉鈕；各群分別累積有效時間，再對準同群接續 |
| 成功與 SAN | 整群收走、停該群聲音，收集／SAN 各結算一次，UI／震動；捕捉器不發聲 |
| 群落補充 | 開場 3 群；捕捉成功先扣 SAN，若仍大於 0，隨機補 1 個本場未出現變體。新群使用新身分及進度 0。 |
| 語意與錄音 | 偵測音量／持續時間，不要求台詞、不做語意辨識；不保存／上傳原始人聲 |
| 異常恢復 | 過期資料不計時，保留各群進度與顯現基準；重連不另開一場 |
| Return | SAN 歸零（任務完成）停止新捕捉，走正常回收；遊玩時長僅供內容量估算 |
| 回收兩步 | 先到站授權，再選螢幕確認；可移開後確認，資格保留至回收／結束，重校準／換機清除 |
| 結算與修復 | 固定清單、登錄類型／變體／群落次數、能量物品、城市修復；事件重送不重演 |
| 收藏卡片 | 只顯示本場已收集變體的圖像、名稱及來源聲音，不列每張卡的群數 |
| 聲部組合 | 每個已收集變體啟用一個聲部，完成時為 5 個聲部；相同組合沿用同一配方 |
| 線上原型 | Vercel Hobby 部署 Next.js，Neon Free 保存成果，預製素材隨網站版本發佈；<br>即時遊戲留本機 |
| 列印設備取得 | 優先借用 80 mm、USB、自動裁刀與 Windows 驅動相容的機型 |
| 結果與紀念品 | Next.js 感謝信／摘要／預製聲部旋律、同 result_id／token、離場重開；<br>每場一張聲音收藏票，含 5 個已收集變體的黑白組合圖、名稱／來源聲音清單及同一成果 QR |
| 資料與重置 | 本機保存確認／outbox／HTTPS 補傳，重置保留成果；清場完成再開下一場 |
| 未定細節 | 各方案自己的討論清單保存參數與驗證項目，不以本表代替規格 |

## 2. 各方案獨立的實作

| 項目 | 紅外線互動投影 | MR | VR |
| --- | --- | --- | --- |
| 開場與教學 | 前導後進入字幕／動畫操作示範 | 前導後進入頭戴內操作示範 | 前導／配戴後，約 15 秒 VR 短版開場，再觀看操作示範 |
| 主畫面 | L 形兩面主投影 | Quest 3 真實環境透視與虛擬疊合 | Quest 3 完整虛擬城市 |
| PC 外部螢幕 | 依投影方案配置 | 觀眾螢幕 1 台＋工作人員螢幕 1 台，共用同一 PC | 觀眾螢幕 1 台＋工作人員螢幕 1 台，共用同一 PC |
| 輸入 | 自製 ESP32-S3 捕捉器／觸控 LCD | Touch Plus／虛擬捕捉器 UI | Touch Plus／虛擬捕捉器 UI |
| 瞄準 | 固定紅外線編碼／中心偏移，辨識點位與對準程度 | Quest 3 頭手追蹤／Unity 射線 | Quest 3 頭手追蹤／Unity 射線 |
| 光罩（Mask） | 有效辨識並對準音虫點位後，固定顯示在該處 | 隨已對位場景表面落點移動，不需先命中音虫 | 隨虛擬場景表面落點移動，不需先命中音虫 |
| 收音與探索區 | 現場麥克風；Unity 場景／任務段落定義探索區 | Quest 3 內建麥克風；展場位置、觀看方向與互動範圍，前方多群回應 | Quest 3 內建麥克風；觀看方向與互動範圍，前方多群回應 |
| 捕捉與遊戲時長 | 依其開發規格配置 | 同群累積有效對準 3 秒；約 5 分鐘內容量，依 SAN 歸零回收 | 同群累積有效對準 3 秒；約 5 分鐘內容量，依 SAN 歸零回收 |
| 移動 | 真實走動／轉向雙牆 | 真實活動區走動，內容留在展場座標 | 單一場景，在實際圓形區以 1:1 轉身／小步移動 |
| 到站 | 被動標籤＋NFC 回收座 | 實際靠近外殼＋控制器進對位區 | 轉向同場景回收站，捕捉器前端進感應區；身體留圓內 |
| 回收外觀 | 實體 NFC 座，雙投影呈現修復 | 唯一實體外殼與虛擬模型／效果對齊 | 完全虛擬站體，不需實體外殼 |
| 開發 | PlatformIO／C++／LVGL、Unity、Gateway、Next.js | Windows Unity／Meta XR／Link、場景射線與動態 Mask、Gateway、Next.js | Windows Unity／OpenXR／場景射線與動態 Mask／Link、Gateway、Next.js |
