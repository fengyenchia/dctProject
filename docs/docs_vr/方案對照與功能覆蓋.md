# 音虫 VR｜方案對照與功能覆蓋

日期：2026-11-18｜版本：VR v0.30

VR 是目前開發主線；紅外線與 MR 已封存，未隨 VR 更新。本表保留呈現方式比較；實作規則以本資料夾的[開發規格](開發規格.md)為準。

## 1. VR 主線功能覆蓋

| 功能 | VR 現行規則 |
| --- | --- |
| 單人與開場 | 一次一位；管理端建立場次，前導後以字幕與動畫引導操作，發聲步驟本階段先不做 |
| 點位與群落 | 有效出現區中隨機分散生成，平時最多 3 群，雨天最多 4 群；每點同時最多一個群落，單隻或一群都算一個捕捉單位。預設 CaptureLab 開場屋內 1 群、屋外 2 群。 |
| 種類與收集 | 3 類各 3 個變體；每場收集 1～5 群，同一變體不重複。群內可有多個同變體個體 |
| 教學數據 | 觀看字幕／動畫示範即可，本階段先不做發聲；展示資料不計入正式 SAN、收藏與成果 |
| 初始探索 | 群落隱藏但存在、持續發聲，先循聲尋找 |
| 循聲與數量 | 海天使／海蛞蝓最多 3 群，有未出現變體及點位就補。SAN 歸零停止補充。 |
| 發聲顯現（VR 後續） | 觀看方向前方範圍內的既有音虫用 3 秒淡入、再用 1 秒淡出；不需先命中目標，不增加群落 |
| 捕捉進度顯現 | 顯現基準與累積捕捉進度採連續線性對應；移開／換群／中斷都保留進度及對應外觀 |
| 捕捉音量 | 目標聲音隨進度降低；移開／中斷保留對應音量，再對準接續。完成後停聲，新群使用原始音量。 |
| 外觀合成（VR 後續） | max（短暫發聲效果，進度顯現基準）；進度 0 時純發聲後回到隱藏，已有進度只回落至基準 |
| 捕捉回饋與 UI | Unity 統一保存捕捉進度；Mask 呈現方式依各方案的定位與照射方式配置 |
| 自動捕捉 | 不按捕捉鈕；各群分別累積有效時間，再對準同群接續 |
| 成功與 SAN | 整群停聲並結算一次，場景音虫退場，捕捉器螢幕顯示精細模型並震動 |
| 群落補充 | A／B 全程保留並補群。第 60 秒加入 C1，第 120 秒雨停，未捕捉 C1 退場。 |
| 語意與錄音 | 偵測音量／持續時間，不要求台詞、不做語意辨識；不保存／上傳原始人聲 |
| 異常恢復 | 過期資料不計時，保留各群進度與顯現基準；重連不另開一場 |
| Return | 至少 1 群可到站回收。SAN 歸零停止新捕捉及補群 |
| 回收兩步 | 先到站授權，再選螢幕確認；可移開後確認，資格保留至回收／結束，重校準／換機清除 |
| 結算與修復 | 登錄實收種類與變體。金色粒子數隨實收改變，搭配城市材質修復。修復後播返回起點語音；90 秒內返回起點，或超時時原地淡黑。左手開信，顯示依實收分級的正文。 |
| 收藏卡片（後續） | 只顯示本場已收集變體的圖像、名稱及來源聲音，不列每張卡的群數 |
| 成果內容 | 實收圖鑑與感謝信，不播放聲音；紙票 QR 直達個人頁 |
| 線上原型 | Vercel Hobby 部署 Next.js，Neon Free 保存成果，預製素材隨網站版本發佈；<br>即時遊戲留本機 |
| 列印設備取得 | 優先借用 80 mm、USB、自動裁刀與 Windows 驅動相容的機型 |
| 結果與紀念品 | Next.js home／results／about／process；卡片總覽可開每位觀眾的個人圖鑑與感謝信，無聲音；<br>每場一張聲音收藏票，QR 直達本場 `/results/<token>`，離場重開沿用同份資料 |
| 資料與重置 | 本機保存確認／outbox／HTTPS 補傳，重置保留成果；清場完成再開下一場 |
| 未定細節 | VR 待決事項與必要測試集中於本資料夾的待確認清單 |

## 2. 呈現方式比較（含封存方案）

| 項目 | 紅外線互動投影 | MR | VR |
| --- | --- | --- | --- |
| 開場與教學 | 前導後進入字幕／動畫操作示範 | 前導後進入頭戴內操作示範 | 前導／配戴後，約 15 秒 VR 短版開場，再觀看操作示範 |
| 主畫面 | L 形兩面主投影 | Quest 3 真實環境透視與虛擬疊合 | Quest 3 完整虛擬城市 |
| PC 外部螢幕 | 依投影方案配置 | 觀眾螢幕 1 台＋工作人員螢幕 1 台，共用同一 PC | 觀眾螢幕 1 台＋工作人員螢幕 1 台，共用同一 PC |
| 輸入 | 自製 ESP32-S3 捕捉器／觸控 LCD | Touch Plus／虛擬捕捉器 UI | Touch Plus／虛擬捕捉器 UI |
| 瞄準 | 固定紅外線編碼／中心偏移，辨識點位與對準程度 | Quest 3 頭手追蹤／Unity 射線 | Quest 3 頭手追蹤／Unity 射線 |
| 光罩（Mask） | 有效辨識並對準音虫點位後，固定顯示在該處 | 隨已對位場景表面落點移動，不需先命中音虫 | 隨虛擬場景表面落點移動，不需先命中音虫 |
| 收音與探索區 | 現場麥克風；Unity 場景／任務段落定義探索區 | Quest 3 內建麥克風；展場位置、觀看方向與互動範圍，前方多群回應 | 後續以 Quest 3 內建麥克風判斷發聲；目前循聲與照射顯現 |
| 捕捉與遊戲時長 | 依其開發規格配置 | 同群累積有效對準 3 秒；約 5 分鐘內容量，依 SAN 歸零回收 | 同群累積有效對準 3 秒；至少 1 群即可回收 |
| 移動 | 真實走動／轉向雙牆 | 真實活動區走動，內容留在展場座標 | 長型城市，原地轉身／左手搖桿平移 |
| 到站 | 被動標籤＋NFC 回收座 | 實際靠近外殼＋控制器進對位區 | 以搖桿走到街尾，捕捉器前端進感應區；身體留圓內 |
| 回收外觀 | 實體 NFC 座，雙投影呈現修復 | 唯一實體外殼與虛擬模型／效果對齊 | 完全虛擬站體，不需實體外殼 |
| 開發 | PlatformIO／C++／LVGL、Unity、Gateway、Next.js | Windows Unity／Meta XR／Link、場景射線與動態 Mask、Gateway、Next.js | Windows Unity／OpenXR／場景射線與動態 Mask／Link、Gateway、Next.js |
