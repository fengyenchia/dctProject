# 音虫 VR｜器材清單

日期：2026-11-08｜版本：VR v0.25

- 原型：**1 套 Meta Quest 3（含 Touch Plus 控制器與腕帶）**、1 台展出電腦、2 台螢幕、1 台 USB 感熱印表機。
- Unity 場景先設 6 個候選出現區，同時隨機啟用最多 3 群；另設 1 座虛擬回收站。
- 一次一位，由頭戴與原廠控制器完成互動。

- 本清單列出 VR 原型所需設備與服務。
- 參考價格「—」表示尚無可核實報價，不代表免費。
- 採購核對台灣來源、統編發票、庫存、保固與套裝內容，不重複計算隨附控制器／配件。
- 參考價格列於本表；借用、採購與實機驗證事項見[待確認清單](待確認與驗證清單.md)。

## 6. 原型與採購原則

- 完成「最多三群的循聲原型測試／發聲顯現／進度與外觀保留 → 捕捉 UI／震動 → 群落生成 →<br>到站確認 → 能量物品／城市修復 → 本機保存／USB 聲音收藏票／Next.js 成果」完整原型。
- 同步驗證圓形活動區、動態光罩、群落判定及圈內回收。

器材數量、正式報價及耗電以本方案的完整連續接待原型核定；頭戴套裝配件不重複計價，備機不增加同時遊玩人數。
