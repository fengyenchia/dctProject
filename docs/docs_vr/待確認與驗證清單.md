## 2. 必要實機測試

- 補測搖桿移動舒適度、房屋碰撞、控制器與線材轉身、雨天音源與粒子效能，以及回收後可移動觀看修復。

P1 先驗證方案能否成立；P2 在完整原型與展場測試。以下尚未完成實測。

| 優先 | 測試項目 | 實測重點 |
| --- | --- | --- |
| P1 | 跨平台電腦模擬 | 2 台 Windows＋1 台 Mac M3 的 Editor 套件匯入、模擬頭手輸入、UI／Mask 與相同資料讀取；Mac 不執行 Windows 專用原生功能。 |
| P1 | 電腦與 USB Link | 最小 Windows 執行檔、頭手輸入／音訊、借用線材與接口、斷線恢復，核對系統／驅動／USB Test。 |
| 後續，本階段先不做 | 發聲收音／AEC | 已有 [U2 實作順序](開發文件/工作包/U2.md#5-發聲顯現後續規劃本階段先不做)與 [X1 實機步驟](開發文件/工作包/X1.md#發聲顯現驗收後續規劃本階段先不做)。開工後測只播放／只發聲／同時播放，驗證誤觸發與回應範圍。 |
| P2 | 效能與顯示 | 最重場景／Mask／雙眼幀率、延遲／顯存、介面可讀性、雙螢幕、管理頁切換與 XR 輸入焦點、連續接待穩定性；<br>比較雙眼捕捉成功前後幀時間，包含雨天＋四群＋正式材質；驗證捕捉音量衰減、移開保留及新群原始音量 |
| P2 | 配戴與活動區 | 原地轉身、左手搖桿移動、伸手回收、邊界與線材、重定位、手抖／疲勞、電量讀取／續航／溫升、清潔及人員協助 |
| P2 | 網路與手機成果 | 五組共用 Wi-Fi、斷線補傳／重啟保存、免費服務首次喚醒與用量、iOS／Android 掃紙票 QR、聲部同步播放與離場重開 |
| P2 | 紙票輸出 | 借用機的 Windows 11 驅動／USB／裁刀、黑白變體辨識、票長／字級／QR 尺寸、連續裁切、缺紙／<br>卡紙／USB 復原、補印與取票動線 |
