# 里程碑與美術期限

測試目標：**2027/1/31 電腦可玩原型**。以下為本次排定的原型開發期限。

- **初版交付**：用佔位素材完成該包開頭的驗收；交付後仍要整合及修正。
- **整合交付**：接上其他工作包與美術，跑完共同流程。
- Quest、AEC 效果及實體出紙依設備另驗證；初版通過不代表實機通過。
- 2026/11～12 月為開發期；下表 1 月日期均為 **2027 年**。

## 4. 原型美術的最低交付

| 類別 | 原型需要 | 可後續增加 |
| --- | --- | --- |
| 城市 | 一個可環顧的代表性區域、遮擋面、修復前後狀態 | 城市遠景密度、額外裝飾與高階特效 |
| 音虫 | 3 基礎模型、各 3 變體；隱藏／顯現可控制 | 額外動作與細緻表情 |
| 捕捉器／回收站 | 可讀的畫面位置、可指向的感應區、簡單修復演出 | 精細機構動畫及裝飾 |
| UI／紀念品 | 主畫面、收藏、回收；9 張圖像及黑白版；票面版型 | 複雜轉場及額外頁面 |
| 聲音 | 每變體 1 來源聲音＋1 旋律聲部；少量城市環境音 | 額外敘事音效與混音細修 |
| 開場／教學 | 約 15 秒短版；循聲／捕捉／回收動畫，發聲字幕 | 最終配樂及精細特效 |

- 素材規格與匯入接法：[美術與聲音交付](共用/美術與聲音交付.md)。
- 每包自測後，依[整合與驗收](共用/整合與驗收.md)合併；不等 1/31 才測完整流程。
