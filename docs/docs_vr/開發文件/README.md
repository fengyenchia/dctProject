## 組員桌面試玩（U0／U1）

1. 拿到同一版專案後，在 Unity Hub 用 **Add project from disk** 加入 `unity-vr`，用 **6000.3.19f1** 開啟，等匯入完成。
2. 在 **Project** 視窗雙擊 **Assets → _Project → Scenes → CaptureLab**。按 Editor 上方 **Play**，點一下 **Game** 畫面取得焦點，按 **Enter** 開始。開場和教學各可再按一次 **Enter** 跳過。
3. 進探索後，用 **WASD** 移動，**直接移動滑鼠**轉頭。**P** 暫停並放開游標，再按 **P** 繼續就能直接轉頭。手動按 **Esc** 放開游標後，用 **Tab** 恢復滑鼠轉向。用畫面中心對準同一群，累積 3 秒會自動捕捉。左側屋內那群要進屋才開始計時。有效探索第 **60 秒**下雨、第 **120 秒**雨停。
4. 抓到至少一群後，到長街尾端靠近回收方塊，稍微往下瞄。等左上出現 **Enter: Confirm recycle** 就按 **Enter**。左上按鍵提示及過場捷徑供開發測試，依畫面提示完成剩下的段落。[U1 跑完一場](工作包/U1.md#2-跑完一場)

U0 回報能否開啟 CaptureLab、進 Play、使用鍵鼠移動，以及 Console 是否有新紅字。附作業系統；遇到錯誤時截第一條新紅字。

## 同一個 repo 的目錄

```text
dctProject/
  unity-vr/     Unity 專案，用 Unity Hub 開啟
  web/          Next.js 網頁，用 pnpm
  gateway/      本機串接服務，用 pnpm
  shared/       共用資料格式與素材對照
  docs/docs_vr/開發文件/
    環境與Git.md      入門：工具安裝與 clone
    Unity基本操作.md  入門：視窗與操作查表
    工作包/      按 U0／U1／U2／U3／I1／W1／I2／X1 實作
    共用/        素材交付、網頁慣例與驗收
    範例程式/    按 U0／U1／U2／U3／I1／W1／I2／X1 分類
```

各程式建立時才加入 repo，共用根目錄 Git；子資料夾不另外 git init。web／gateway 各自保留 package.json 與 pnpm-lock.yaml。

| 工作 | 終端機位置／操作 |
| --- | --- |
| Web | `cd web` → `pnpm dev`；根目錄可用 `pnpm --dir web dev`。 |
| Gateway | `cd gateway` → `pnpm dev`；根目錄可用 `pnpm --dir gateway dev`。 |
| Unity | Unity Hub 開啟 `unity-vr/`。 |
