## 同一個 repo 的目錄

```text
dctProject/
  unity-vr/     Unity 專案，用 Unity Hub 開啟
  web/          Next.js 網頁，用 pnpm
  gateway/      本機串接服務，用 pnpm
  shared/       共用資料格式與素材對照
  docs/docs_vr/開發文件/
    環境與Git.md      入門：工具安裝與 clone
    Unity基本操作.md  入門：視窗與操作查表
    工作包/      按 U0／U1／U2／U3／I1／W1／I2／X1 實作
    共用/        素材交付、網頁慣例與驗收
    範例程式/    按 U0／U1／U2／U3／I1／W1／I2／X1 分類
```

各程式建立時才加入 repo，共用根目錄 Git；子資料夾不另外 git init。web／gateway 各自保留 package.json 與 pnpm-lock.yaml。

| 工作 | 終端機位置／操作 |
| --- | --- |
| Web | `cd web` → `pnpm dev`；根目錄可用 `pnpm --dir web dev`。 |
| Gateway | `cd gateway` → `pnpm dev`；根目錄可用 `pnpm --dir gateway dev`。 |
| Unity | Unity Hub 開啟 `unity-vr/`。 |

- 遊戲規則以[開發規格](../開發規格.md)為準；未定事項／設備測試在[驗證清單](../待確認與驗證清單.md)。
- [範例程式入口](範例程式/README.md)已按工作包分類；需依工作包指示複製，本資料夾不是已建好的 Unity／Web 專案。
- 每包依「前置→放檔→操作→預期→驗收」進行；範例可編譯不等於已通過 Unity 場景、Quest 或展場驗收。
