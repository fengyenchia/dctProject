## 1. 第一次啟動

| 步驟 | 操作 | 預期結果 |
| --- | --- | --- |
| 1 | 按 Editor 上方 ▶ Play，點 Game 分頁 | 左上有 DESKTOP LAB 與 Start intro。 |
| 2 | 點 Start intro | Phase 為 Intro。 |
| 3 | 等約 15 秒 | 進 Tutorial；此範例先用示範文字替代正式動畫。 |
| 4 | 再等 16 秒 | 進 Active：SAN 100、Collected 0；預設 CaptureLab 屋內／屋外各 1 群。 |
| 5 | 按住滑鼠右鍵拖動，WASD 移動 | 循聲探索長街，鼠鍵只供桌面測試。 |
| 6 | 將畫面中心對準聲源，有效對準累積 3 秒 | 灰模漸顯、聲音漸小。成功時停聲、SAN 80，短暫顯示正式外觀後退場。未接正式素材時顯示測試色。 |

後續重測可用 Developer skip current demonstration 跳過當前示範；正式版不保留此按鈕。

桌面瞄準射線由相機中心發出；到站使用的模擬前端位置另外計算。U3 接控制器後則改用 AimOrigin／Tip。

## 2. 跑完一場

| 操作 | 應看到／聽到 |
| --- | --- |
| 對準 1 秒，移開，再對準約 2 秒 | 同群接續進度，完成一次捕捉。 |
| 晴天抓完前 4 群 | SAN 80／60／40／20；尚有未出現變體時補群，同時最多 2 群。 |
| 抓完第 5 群 | SAN 0，Phase 變 Return；不再補群或接受發聲。 |
| 已抓 1～5 群，以 WASD 到長街另一端，稍向下瞄準回收方塊 | 前端靠近站面後出現 Confirm recycle。用 1 群提前回收與 5 群上限各測一場。 |
| 按 Confirm recycle | 進 Recycling。 |
| 按 Complete placeholder repair | 進 ExitRoute。修復期間及修復後都可移動。 |
| 沿原路走回出生點 | 進入 EndingVideo。已接 U3 時會自動淡黑後顯示信封；純桌面基線可以用 Complete placeholder ending video 略過佔位結尾。 |
| 按 Open thank-you letter，再按 Finish experience | 查看 1／2～3／4～5 群對應版本，再進 Ending。桌面按鈕由 U3 接正式介面。 |
| 按 Write lab result JSON | Console 顯示 `lab-result.json` 的完整路徑。 |

這份 JSON 是規則練習檔；正式 Gateway 成果與保存 ACK 在I1處理。

## 3. 下雨事件

1. 進 Active 後讓 Weather 計時走到 180 秒，中途可測暫停時不累計。
2. 切換時，未捕捉的 A／B 群落、聲源和進度退場，C 以新身分與 0 進度出現。已收藏與 SAN 不變。
3. 另外趁晴天抓 1 群後回收。回收後等超過三分鐘，不應觸發雨天。
4. U2 可在 DesktopLab 的 Rain Effects 欄指向雨粒子及雨打鐵皮聲的父物件。程式於切換時啟用，新場重置關閉。

## 卡住時

| 現象 | 檢查／修正 |
| --- | --- |
| Add Component 找不到 DesktopLab | U0 四個 `.cs` 是否都複製？Console 是否有紅字？ |
| `Assign PrototypeReveal shader first` | 停止 Play，補 Reveal Shader，再執行。 |
| 一開始沒看見音虫 | 先循聲轉向，再用捕捉器照射聲源附近確認。 |
| 對準卻不增加 | 群落要在畫面中心；看左上進度是否變化，UI Busy 不可勾。 |
| 回收不出現 | 先確認已收集至少 1 群。角色走近長街另一端的回收方塊，再略往下瞄。 |
| 音量太大 | 先降電腦音量；U2設定群落 Base Volume。 |
| 停止 Play 後物件不見 | 這些是執行時生成，正常；不要把執行期物件當作已保存場景。 |
