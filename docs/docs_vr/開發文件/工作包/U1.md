以下使用 U1 的桌面操作。U3 接入控制器後，共用的 `CaptureLab` 改用 U3 的模擬器操作，捕捉和回收的預期結果仍依本包核對。

## 1. 第一次啟動

| 步驟 | 操作 | 預期結果 |
| --- | --- | --- |
| 1 | 按 Editor 上方 ▶ Play，點一下 Game 畫面 | 左上有 DEVELOPMENT TEST 及 Enter: Start intro。 |
| 2 | 按 Enter | Phase 為 Intro。 |
| 3 | 等約 15 秒 | 進 Tutorial；此範例先用示範文字替代正式動畫。 |
| 4 | 再等 16 秒 | 進 Active：SAN 100、Collected 0；預設 CaptureLab 屋內 1 群、屋外 2 群。 |
| 5 | 直接移動滑鼠轉向，WASD 移動 | 進 Active 時會鎖定游標，可在長街循聲探索。 |
| 6 | 將畫面中心對準聲源，有效對準累積 3 秒 | 場景模型漸顯、聲音漸小。成功時停聲、SAN 80，場景音虫退場，由 U3 接捕捉器螢幕的精緻材質版。 |

後續重測可按 Enter 跳過當前示範。左上提示及過場捷徑供開發測試。

桌面瞄準射線由相機中心發出；到站使用的模擬前端位置另外計算。U3 接控制器後則改用 AimOrigin／Tip。

P 暫停並釋放游標，再按 P 繼續就能直接轉頭。手動按 Esc 釋放游標後，按 Tab 恢復轉頭。若鍵盤沒反應，先點一下 Game 畫面。

## 2. 跑完一場

| 操作 | 應看到／聽到 |
| --- | --- |
| 對準 1 秒，移開，再對準約 2 秒 | 同群接續進度，完成一次捕捉。 |
| 捕捉到一半按 P，再按 P 後移動滑鼠 | 暫停時游標釋放且計時停止。續玩時游標自動鎖回，畫面可立即轉向。再對準同群接續進度。 |
| 晴天抓完前 4 群 | SAN 80／60／40／20；尚有未出現變體與未用點位時補群，平時最多 3 群，雨天最多 4 群。 |
| 點位 | 記下已捕捉或因雨停退場的位置，新群不得出現在本場用過的位置。重開新一場後可再次使用。 |
| 抓完第 5 群 | SAN 0，Phase 變 Return；不再補群或接受發聲。 |
| 已抓 1～5 群，以 WASD 到長街另一端，稍向下瞄準回收方塊 | 前端靠近站面後出現 Enter: Confirm recycle。用 1 群提前回收與 5 群上限各測一場。 |
| 按 Enter 確認回收 | 進 Recycling。 |
| 看到 Enter: Complete placeholder repair 後按 Enter | 進 ExitRoute。修復期間及修復後都可移動。 |
| 修復完成後，聽返回語音，90 秒內返回左端起點的亮青色圓盤 | 圓盤在 ExitRoute 才顯示，從修復完成起計時 90 秒；暫停時凍結。開場或探索中經過起點不會觸發，超時則原地進結尾。踏入後桌面原型自動進 ThankYou、放開游標，左上顯示 Enter: Open thank-you letter。已接 U3 的場景依淡黑演出進入開信畫面。 |
| 依左上提示按 Enter 開信，再按一次 Enter 結束 | 查看 1／2～3／4～5 群對應版本，再進 Ending。 |
| 在 Ending 再按一次 Enter | Console 顯示 `lab-result.json` 的完整路徑。 |

這份 JSON 是規則練習檔；正式 Gateway 成果與保存 ACK 在I1處理。

## 3. 下雨事件

1. 進 Active，先把一群海天使或海蛞蝓照出部分輪廓，再移開。等左上計時到 60 秒，確認 Weather 變 rain、C1 加入，總數最多 4 群。原群的位置、聲音與進度保留。可中途按 P 確認暫停不累計。
2. 一場保留 C1 至第 120 秒。確認 Weather 回到 dry、C1 退場，原群仍可繼續捕捉。另一場先抓 C1，確認雨天剩餘時間內不再出魟魚。
3. 另開一場，晴天抓 1 群便回收，確認回收後停止探索計時。
4. 粒子、雨聲與 Inspector 接線見 [U2｜雨景與雨聲](U2.md#雨景與雨聲)。

## 卡住時

| 現象 | 檢查／修正 |
| --- | --- |
| Add Component 找不到 DesktopLab | U0 四個 `.cs` 是否都複製？Console 是否有紅字？ |
| `Assign PrototypeReveal shader first` | 停止 Play，補 Reveal Shader，再執行。 |
| 一開始沒看見音虫 | 先循聲轉向，再用捕捉器照射聲源附近確認。 |
| 對準卻不增加 | 群落要在畫面中心；看左上進度是否變化，UI Busy 不可勾。 |
| 回收不出現 | 先確認已收集至少 1 群。角色走近長街另一端的回收方塊，再略往下瞄。 |
| 看不到結尾圓盤 | 左上若仍是 Recycling，按 Enter 完成佔位修復。看到 ExitRoute 後，返回左端起點查看地面。自訂場景依 U3 設置地標。 |
| 音量太大 | 先降電腦音量；U2設定群落 Base Volume。 |
| 停止 Play 後物件不見 | 這些是執行時生成，正常；不要把執行期物件當作已保存場景。 |
