## 1. 第一次啟動

| 步驟 | 操作 | 預期結果 |
| --- | --- | --- |
| 1 | 按 Editor 上方 ▶ Play，點 Game 分頁 | 左上有 DESKTOP LAB 與 Start intro。 |
| 2 | 點 Start intro | Phase 為 Intro。 |
| 3 | 等約 15 秒 | 進 Tutorial；此範例先用示範文字替代正式動畫。 |
| 4 | 再等 16 秒 | 進 Active：SAN 100、Collected 0/5、3 筆群落資料。 |
| 5 | 按住滑鼠右鍵拖動 | 視角轉向；右鍵是開發替代操作。 |
| 6 | 按 V | 前方音虫 3 秒淡入、1 秒淡出；這是事件測試鍵，不是麥克風。 |
| 7 | 將畫面中心指向一隻音虫，維持約 3 秒 | 該筆進度上升；聲音變小；完成後 SAN 80。 |

後續重測可用 Developer skip current demonstration 跳過當前示範；正式版不保留此按鈕。

桌面瞄準射線由相機中心發出；到站使用的模擬前端位置另外計算。U3 接控制器後則改用 AimOrigin／Tip。

## 2. 跑完一場

| 操作 | 應看到／聽到 |
| --- | --- |
| 對準 1 秒，移開，再對準約 2 秒 | 同群接續進度，完成一次捕捉。 |
| 抓完前 4 群 | SAN 80／60／40／20；每抓一群補一群，同時最多 3 群。 |
| 抓完第 5 群 | SAN 0，Phase 變 Return；不再補群或接受發聲。 |
| 轉向背後，稍向下看回收方塊 | 練習捕捉器前端靠近站面後出現 Confirm recycle。 |
| 按 Confirm recycle | 進 Recycling。 |
| 按 Complete placeholder repair | 進 Ending；這個按鈕暫代演出完成事件。 |
| 按 Write lab result JSON | Console 顯示 `lab-result.json` 的完整路徑。 |

這份 JSON 是規則練習檔；正式 Gateway 成果與保存 ACK 在I1處理。

## 卡住時

| 現象 | 檢查／修正 |
| --- | --- |
| Add Component 找不到 DesktopLab | U0 四個 `.cs` 是否都複製？Console 是否有紅字？ |
| `Assign PrototypeReveal shader first` | 停止 Play，補 Reveal Shader，再執行。 |
| 一開始沒看見音虫 | 正常；要先循聲轉向，按 V 幫助找位置。 |
| 按 V 沒反應 | Game 視窗有焦點？目前為 Active？先按住右鍵看向其他方向。 |
| 對準卻不增加 | 群落要在畫面中心；看左上進度是否變化，UI Busy 不可勾。 |
| 回收不出現 | 先確認 SAN 0；轉向背後方塊並略向下，讓前端接近它。 |
| 音量太大 | 先降電腦音量；U2設定群落 Base Volume。 |
| 停止 Play 後物件不見 | 這些是執行時生成，正常；不要把執行期物件當作已保存場景。 |
