# W1｜成果總覽與個人成果網頁

[分段排程與整合期限](../02_里程碑與美術期限.md)

| 開始日期 | 初版完成日期 |
| --- | --- |
| **2026/12/29** | **2027/1/7** |

初版驗收：home／results／about／process 入口、卡片總覽及個人成果頁可用；2027/1/26 前整合紙票 QR。個人頁顯示觀眾編號、實收圖鑑與感謝信，不播放聲音。正式網站依 3/15～4/15 排程。

分支：`web/souvenir`；`web/admin` 留作後續選配。開工前依[網頁／Gateway 環境](../共用/網頁開發慣例.md)準備 Node.js 24 LTS、pnpm 11.9.0。

第 1～3 節先用樣本，不必等待 Quest 或 I1。第 4 節接雲端，第 5 節的管理頁先不做、保留來源；票面與列印由 [I2](I2.md)接續。

## 網站入口

| 路徑 | 功能 |
| --- | --- |
| `/`（home） | 首頁，呈現主視覺與作品入口。 |
| `/results` | 所有已上傳成果的卡片總覽；點卡片進入該份成果，每頁 12 張。 |
| `/results/<token>` | 紙票 QR 直接開啟該份個人成果；可前往總覽，再看其他人的成果。 |
| `/about` | 團隊介紹；收到正式資料後替換佔位內容。 |
| `/process` | 製作歷程，資料放 `web/data/process.json`。 |
| `/display` | 前導影片播放頁；導覽先保留 Display 入口，影片後續交付。 |
| `/api/results?page=1` | 唯讀卡片清單，不提供遊戲操作。 |
| `/api/results/<token>` | 讀取同一份固定成果，重新整理不換配方。 |

- 觀眾不需登入；個人成果也會出現在公開總覽，token 是唯讀網址識別，不是私密保護。
- 正式卡片與個人頁要顯示哪些內容，見[討論清單](../../待確認與驗證清單.md)。個人頁固定包含觀眾編號、實收圖鑑與感謝信；介紹文案及正式視覺另交。
- 總覽卡片只顯示一張封面與成果編號（result_id），不列音虫名稱或文字按鈕；整張卡片仍可點入個人頁。封面先用該份成果第一個變體的圖片，缺圖只顯示圖示。
- 兩套設備輪替、一次一套／一位觀眾；網站彙整各場成果，不建立雙人或雙場同步系統。

## 完成條件

- [ ] 導覽可切換首頁主視覺、成果總覽、團隊介紹；每張卡片開對應個人成果。
- [ ] 紙票 QR 直接進自己的 `/results/<token>`；個人頁可到總覽並開其他人的成果。
- [ ] 顯示觀眾編號、實收圖鑑及感謝信；沒有播放按鈕，也不請求音檔。
- [ ] 重開連結仍是相同配方／素材。
- [ ] 總覽只列已上傳成果；空清單、載入失敗、分頁與無效個人連結有對應畫面。
- [ ] 將固定成果 API 與網址交 I2 串接。

範例有 1／3／5 群三筆獨立成果，供卡片與個人頁測試。若保留感謝信，正式稿需與 U3 共用同一版文字。

## 1. 建立一次網頁專案

repo 已有 `web/package.json` 時，先在 web 執行 `pnpm install --frozen-lockfile`，沿用既有 UI 元件與設定；不重建專案。

套件管理使用 **pnpm 11.9.0**。僅第一次建置者在 **repo 根目錄**執行：

```text
pnpm create next-app@16 web --use-pnpm --disable-git
```

| 選項 | 選擇 |
| --- | --- |
| 自訂設定 | TypeScript、ESLint、Tailwind、App Router：Yes。 |
| `src/` 目錄 | No，沿用組內目錄慣例。 |
| React Compiler／Cache Components | 原型先不加，降低入門設定量。 |
| alias | `@/*`。 |

建立後開啟 `web/next.config.ts`，確認以下設定；已有欄位就改原值，其餘設定保留。範例使用 `force-dynamic`，不搭配 Cache Components。

```ts
cacheComponents: false,
partialPrefetching: false,
```

建立後，進入 **repo/web** 再執行：

```text
cd web
pnpm add server-only @neondatabase/serverless
pnpm add @radix-ui/react-slot @radix-ui/react-avatar @radix-ui/react-dialog class-variance-authority clsx tailwind-merge @tabler/icons-react axios motion
pnpm add -D typescript@5.9.3 @tailwindcss/postcss@4.3.3
pnpm dev
```

- 開 `http://localhost:3000`；完成下一節後顯示首頁主視覺佔位與三頁導覽。
- 在 `web/package.json` 設定 `"packageManager": "pnpm@11.9.0"`；已有此欄位就修改原值，只保留一個。
- Tailwind 沿用 repo 的 `web/postcss.config.mjs`（`@tailwindcss/postcss`）；不用 `@tailwindcss/turbopack` 自訂 loader，避免樣式更新仍顯示舊版。
- 提交 `web/package.json`、`web/pnpm-lock.yaml`；同一 web 只保留 pnpm 的 lockfile。
- 目錄及後續 UI／API 套件依[網頁開發慣例](../共用/網頁開發慣例.md)取用；本章先用 Tailwind 與附帶元件完成串接。

其他組員拉取後，從 repo 根目錄執行：

```text
cd web
pnpm install --frozen-lockfile
pnpm dev
```

日常啟動同樣先確認終端機在 web；若留在 repo 根目錄，可直接用 `pnpm --dir web dev`。Unity／Gateway 各用自己的入口。

### 3.2 接 I1 的成果

| 步驟 | 操作 | 預期 |
| --- | --- | --- |
| 1 | 啟動 Gateway | `127.0.0.1:8788/health` 正常。 |
| 2 | 在 `web/.env.local` 加 `GATEWAY_HTTP_BASE=http://127.0.0.1:8788`，重開 dev server | 環境變數只供伺服器讀取。 |

### 3.3 排錯

| 狀況 | 檢查 |
| --- | --- |
| Module not found | 依第 2 節放檔，路徑 alias 為 `@/*`。 |
| 找不到樣本 JSON | 將 I1 的 sample-result.json 複製為 `web/lib/fixtures/result-ready.example.json`。 |

## 4. 雲端 API：先本機接資料庫，再部署

| 步驟 | 操作 | 預期 |
| --- | --- | --- |
| 1 | Neon 建立原型專案；開 SQL Editor | 選原型資料庫，不使用正式資料測刪除。 |

| 教學來源 | 放到 web |

### 4.2 用真實結果測上傳

先完成 I1／I2。Gateway 的 .env 改以下值，再開 pnpm dev:delivery：

| Gateway 設定 | 本機測試值 |
| --- | --- |
| INGEST_URL | http://127.0.0.1:3000/api/ingest |
| INGEST_SECRET | 與 web 相同 |
| ALLOW_LOCAL_INGEST | 1；只用於回環測試。 |
| RESULTS_BASE_URL | http://localhost:3000/results；不要當正式票務網址。 |

| 測試 | 預期 |
| --- | --- |
| Unity 收集／回收→RESULT_SAVED | Gateway upload_status 由 pending 轉 uploaded；Neon 多一列。 |
| GET http://localhost:3000/api/results/本場token | 200，只有固定成果，不含密鑰或原始收音。 |
| 再送同 result／相同內容 | 列數不增加，回相同成功。 |
| 同 result 改內容後測上傳 | 409；不可覆蓋原成果。不要修改保留中的正式待交付檔。 |
| 停 Next，產生另一份結果，再重開 | I2 自動補傳；token 不變。 |
| 隨機錯 token | 404；頁面顯示尚未就緒或無效。 |
| 開 `/results` 與 `/api/results?page=1` | 顯示已上傳成果，最新在前；每張連結開同一筆個人成果。 |
| 建立超過 12 筆不同測試結果 | 可翻到下一頁；只回傳卡片資料，不帶 session、SAN、裝置狀態或管理密鑰。 |
| 雲端零筆／暫時無法查詢 | 分別顯示空清單／重試提示；API 失敗回 503，不顯示假成果。 |
