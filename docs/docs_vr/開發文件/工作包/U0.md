初版驗收：三台可開同一專案；版本、Git 與 CaptureLab 基線可用。

分支：`unity/setup`。先完成[環境與 Git](../環境與Git.md)的工具安裝與 clone，再按下方操作。

本包由 **嘉** 建立並匯入一套共用腳本與 Shader；其他兩人拉取後確認可開啟、無編譯錯誤，不重複建專案或匯入腳本。

## 1. 建立共用 Unity 專案

| 步驟 | 操作 | 預期結果 |
| --- | --- | --- |
| 1 | 指定 U0 主責；其餘人先不要各建一份正式專案 | 後續只合併同一套 ProjectSettings。 |
| 2 | Hub → New project → Editor 6000.3.19f1 → Universal 3D | 選 URP，不選 High Definition 3D。 |
| 3 | Project name 填 `unity-vr`；Location 選 repo 根目錄。Windows 是 `C:\dctProject`，Mac 選 clone 的資料夾 | 建好後路徑為 `repo/unity-vr/Assets`；不要變成 `unity-vr/unity-vr/`。 |
| 4 | Edit → Project Settings → Editor：Asset Serialization 為 Force Text | Scene／Prefab 使用可追蹤的文字格式。 |
| 5 | Version Control 模式設 Visible Meta Files | 素材 `.meta` 隨檔案一併提交。 |
| 6 | 建 `Assets/_Project/`，依下表放檔 | 原創內容與外掛／Samples 分開。 |
| 7 | 初次提交後，其他人拉取 repo；Hub → Add → 選 `unity-vr/` | 不重新建專案，讓 Unity 重建自己的 Library。 |

```text
unity-vr/Assets/_Project/
  Scenes/          Bootstrap、Integration、個人測試場景
  Scripts/         Core、Input、Presentation、Integration
  Prefabs/         Bugs、Catcher、Station、UI
  Materials/       顯現材質、Mask
  Data/            變體與布局設定
  Art/             匯入模型、貼圖與動畫
  Audio/           Sources、Stems、Environment
```

## 2. 安裝 Input System

| 步驟 | 在哪裡操作 | 填什麼／做什麼 | 應看到 |
| --- | --- | --- | --- |
| 1 | Window → Package Manager → `+` | Install package by name；Name `com.unity.inputsystem`、Version `1.20.1` | 套件顯示已安裝。 |
| 2 | Edit → Project Settings → Player → Other Settings | Active Input Handling 選 Input System Package (New) | 出現重新啟動提示。 |
| 3 | 按提示重開 Editor | 重新開啟同專案 | Console 無編譯紅字。 |

## 3. 準備場景與檔案

| 步驟 | 操作 | 結果 |
| --- | --- | --- |
| 1 | File → New Scene → Basic（URP）→ Create | 先用新場景，不改別人的場景。 |
| 2 | File → Save As → `Assets/_Project/Scenes/CaptureLab.unity` | Project 看得到 CaptureLab。 |
| 3 | Project 建 `Assets/_Project/Scripts/Tutorial/` | 本套練習腳本先放一起。 |
| 4 | 複製下表 4 個 `.cs` 進 Tutorial | 等待編譯，無紅字。 |
| 5 | 複製 Shader 到 `Assets/_Project/Materials/` | Project 看得到 PrototypeReveal。 |

| 檔案 | 用途 | 要掛在哪裡 |
| --- | --- | --- |
| [VariantCatalog.cs](../範例程式/U0/VariantCatalog.cs) | 9 變體的名稱、來源及圖像資料 | U3 接素材時掛 DesktopLab。 |
| [GameRules.cs](../範例程式/U1/GameRules.cs) | 階段、生成、捕捉、SAN | 不掛物件。 |
| [BugView.cs](../範例程式/U0/BugView.cs) | 顯現及群落聲音 | 本章由程式加入；U2做 Prefab。 |
| [DesktopLab.cs](../範例程式/U0/DesktopLab.cs) | 桌面操作與練習場景 | 下一步的 DesktopLab 空物件。 |
| [PrototypeReveal.shader](../範例程式/U0/PrototypeReveal.shader) | 音虫透明度、圓形 Mask | 拖到元件欄位，不是 Add Component。 |

## 4. 掛入口元件

1. Hierarchy 右鍵 → Create Empty，命名 `DesktopLab`。
2. 選 DesktopLab → Add Component → 搜尋並加入 `DesktopLab`。
3. 依下表填 Inspector，File → Save。

| DesktopLab 欄位 | 本章設定 |
| --- | --- |
| Reveal Shader | 拖 Project 的 PrototypeReveal Shader。 |
| Source Clips | Size 9，先全部留空；執行時用低音量測試音色。 |
| Group Prefab／Station Anchor／Station Zone | 先留 None。 |
| Variant Prefabs | Size 0；美術模型接入時才填九格。 |
| Spawn Points | Size 0；程式使用內建六個候選區。 |
| Create Lab Geometry／Show Developer Panel／Automatic Demos／Pose Valid | 勾選。 |
| Use External Pose／UI Busy | 不勾。 |
| Tracked Head／Tracked Aim／Tracked Tip | 留 None；U3才接。 |

**檢查：**Hierarchy 此時只有場景原有相機／燈光，以及 DesktopLab；地面、牆與音虫到 Play 才生成。

## 5. 其他兩台電腦驗證

1. 依[環境與 Git](../環境與Git.md)取得最新 `main`，從 **Unity Hub → Add project from disk** 加入同一個 `unity-vr/`。
2. 用 Unity 6000.3.19f1 開啟，等匯入和編譯完成。從 **Project** 開啟 `Assets/_Project/Scenes/CaptureLab.unity`，在 **Console** 確認無編譯錯誤。
3. 各自記下作業系統與檢查結果，交給 U0 負責人登記。
