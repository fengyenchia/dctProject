## 1. 裝套件與匯入樣本

| 步驟 | 操作 | 結果 |
| --- | --- | --- |
| 1 | Package Manager → `+` → Install package by name | 安裝下表固定版本。 |
| 2 | 選 XR Interaction Toolkit → Samples | Starter Assets、XR Interaction Simulator 分別按 Import；不選 Legacy。 |
| 3 | Project 的 Assets/Samples 展開 | 找到 XRI／3.3.2 下匯入的資料夾。 |
| 4 | 複製 PresentationLab（尚未交付時用 CaptureLab），改名 `XrLab` 並開啟 | 保留原版測試入口。 |

| Package Name | Version |
| --- | --- |
| `com.unity.xr.interaction.toolkit` | 3.3.2 |
| `com.unity.xr.openxr` | 1.16.1 |
| `com.unity.inputsystem` | 1.20.1；已裝則不重裝。 |

這一階段只安裝上表套件及其相依項目；沿用一套 XRI Rig，不另匯入 Meta Core／All-in-One 的相機或互動範例。

## 2. 放入一套 Rig

1. 停用原場景 Main Camera；不要停用稍後匯入 Rig 內的相機。
2. Project 搜尋 `XR Origin (XR Rig)`，拖一份 Prefab 到 Hierarchy。
3. 搜尋 `XR Interaction Simulator`，拖一份 Prefab 到 Hierarchy。
4. 選 XR Origin，世界 Position／Rotation 0、Scale 1。
5. 展開 XR Origin：保留 Camera Offset、Main Camera、Left Controller、Right Controller。
6. 找其 Locomotion 子物件，取消啟用；本作品不使用移動／瞬移／搖桿旋轉。
7. Play，確認模擬器有操作面板；按 Tab 切換模式、`[`／`]` 切左右控制器，其他鍵看面板標示。
8. 確認頭手可動後停止 Play。

| 檢查 | 要看到什麼 |
| --- | --- |
| 相機／AudioListener | 只有 Rig 裡一套啟用。 |
| Input Action Manager | Actions 清單有 Starter Assets 的 `XRI Default Input Actions`；空白才補拖。 |
| 模擬器 | 本章手動放 Prefab，不再勾另一份自動加入。 |
| 地面高度 | 模擬頭部約在地面上 1.6 m；高度由模擬器輸入調整，不放大 XR Origin。 |

## 3. 建捕捉器

在右控制器下建立以下階層；先用 Cube 暫代美術模型。

```text
Right Controller
  CatcherRoot
    Model
    AimOrigin
    Tip
    ScreenCanvas（下一節建立）
```

| 物件 | Local Position | Local Rotation | Local Scale／其他 |
| --- | --- | --- | --- |
| CatcherRoot | 0, 0, 0 | 0, 0, 0 | 1, 1, 1。 |
| Model（Cube） | 0, 0, 0.07 | 0, 0, 0 | 0.12, 0.08, 0.18；移除 Box Collider。 |
| AimOrigin（空物件） | 0, 0, 0.18 | 0, 0, 0 | Z 軸朝裝置前方。 |
| Tip（空物件） | 0, 0, 0.18 | 0, 0, 0 | 供近距離到站使用。 |

DesktopLab 欄位：

| 欄位 | 從 Hierarchy 拖入／設定 |
| --- | --- |
| Use External Pose | 勾選。 |
| Tracked Head | XR Origin → Camera Offset → Main Camera。 |
| Tracked Aim | AimOrigin。 |
| Tracked Tip | Tip。 |
| Show Developer Panel | 先勾，從電腦按開始及暫代修復完成。 |
| Pose Valid | 模擬測試先勾；此欄位不是正式追蹤保護實作。 |

**檢查：**Play 後用模擬器移動右手，Mask 跟手而非頭部；不再用U1滑鼠視角當瞄準。

## 4. 建 World Space UI

1. GameObject → XR → UI Canvas；命名 `ScreenCanvas`。
2. 拖到 CatcherRoot 下；保留工具建立的 XR UI EventSystem。
3. Canvas Render Mode 確認 World Space；Event Camera 拖 Rig 的 Main Camera。
4. Rect Transform Width `600`、Height `400`；Local Scale 三軸 `0.0003`。
5. Local Position `(0, 0.07, 0.09)`、Rotation `(60, 0, 0)`，先得到約 18×12 cm 螢幕。
6. Canvas 加 Image 作底色，勾 Raycast Target；加入下表階層。
7. 首次建立 TMP 文字若要求匯入資源，按 Import TMP Essentials。
8. 複製 [LabPanel.cs](../範例程式/U3/LabPanel.cs)及 [CollectionCard.cs](../範例程式/U3/CollectionCard.cs)到 Scripts/Tutorial；LabPanel 掛在 ScreenCanvas。

```text
ScreenCanvas（Canvas、Image、LabPanel）
  StatusText（UI → Text - TextMeshPro）
  MainButton（UI → Button - TextMeshPro）
  CollectionButton（UI → Button - TextMeshPro）
  MainPage（空 UI RectTransform）
    HintText
  CollectionPage（空 UI RectTransform）
    CollectionText
  RecyclePage（空 UI RectTransform）
    ConfirmButton
```

建三個 Page：在 Canvas 下用 UI → Image 建立並改名，再 Remove Component 移除 Image，保留 RectTransform。

| UI 物件 | Pos X／Y | Width／Height | 內容 |
| --- | --- | --- | --- |
| StatusText | 0／135 | 560／110 | 字級 26；先填 SAN。 |
| MainButton | -145／40 | 270／55 | HOME。 |
| CollectionButton | 145／40 | 270／55 | COLLECTION。 |
| 三個 Page | 0／-95 | 560／170 | Anchor／Pivot 均為中心；只有一頁顯示。 |
| HintText | 0／0（相對 MainPage） | 540／150 | LISTEN, SPEAK, AIM。 |
| CollectionText | 0／0（相對 CollectionPage） | 540／150 | 字級 24，靠左上。 |
| ConfirmButton | 0／0（相對 RecyclePage） | 400／65 | CONFIRM RECYCLE。 |

所有 TMP 文字先取消 Raycast Target，讓 Button 底圖接收點擊；Canvas 底圖維持勾選以偵測 UI hover。

## 5. 接欄位與按鈕

| ScreenCanvas 的 LabPanel 欄位 | 拖入 |
| --- | --- |
| Lab | DesktopLab 物件。 |
| Status Text／Collection Text | 對應的 TMP 文字物件。 |
| Main Page／Collection Page／Recycle Page | 對應三個 Page。 |
| Confirm Button | RecyclePage 裡的 ConfirmButton。 |

依[共用按鈕接法](../Unity基本操作.md#接-buttonunityevent)設定：

| Button | 接收物件 | On Click 方法 |
| --- | --- | --- |
| MainButton | ScreenCanvas | LabPanel → ShowMain()。 |
| CollectionButton | ScreenCanvas | LabPanel → ShowCollection()。 |
| ConfirmButton | ScreenCanvas | LabPanel → ConfirmRecycle()。 |

- 選 EventSystem：只啟用 XR UI Input Module，不能同時留另一個輸入模組。
- 選左手 Ray Interactor：開 UI Interaction；UI Select 使用 Starter Assets 綁定。
- 此時右手持捕捉器、左手指向螢幕按扳機；滑鼠不是正式介面操作。
- LabPanel 自動在 UI hover 時阻擋捕捉並收 Mask，移開後恢復；不用另外手動勾 UI Busy。

## 6. 換成自己建的回收站

| 步驟 | 操作 | 設定 |
| --- | --- | --- |
| 1 | Hierarchy 建空物件 `StationRoot` | 世界 Position `(0, 0.9, -0.65)`，Rotation 0、Scale 1。 |
| 2 | 其下建 Cube `Body` | Local Position 0、Scale `(0.6, 0.5, 0.3)`；保留 Collider。 |
| 3 | 其下建空物件 `VisitZone`，加 Box Collider | 勾 Is Trigger；Local Position `(0, 0, 0.22)`，Size `(0.6, 0.5, 0.4)`。 |
| 4 | DesktopLab → Station Anchor | 拖 StationRoot；不再另外產生練習站體。 |
| 5 | DesktopLab → Station Zone | 拖 VisitZone 的 Collider。 |
| 6 | Play，捕捉 5 群 | SAN 0 後才轉回收。 |
| 7 | 轉向站體，把捕捉器 Tip 放進 VisitZone | 螢幕自動開 RecyclePage。 |
| 8 | 移開 Tip，以另一手點確認 | 進 Recycling；剩餘音虫與聲音退場，收藏保留，不重複登錄。 |
| 9 | 從電腦按 Complete placeholder repair | 暫代修復動畫完成；之後由動畫事件呼叫同一方法。 |

站體固定在初始朝向後方，不每幀移到頭部後面。這版活動圈中心先設世界原點；正式布展另作校正。

## 7. 捕捉震動與左右手選擇

1. 複製 [CaptureHaptics.cs](../範例程式/U3/CaptureHaptics.cs)，掛在 DesktopLab 物件。
2. DesktopLab 的 On Captured 按 `+`，拖同一物件，選 CaptureHaptics → Pulse()。
3. 複製 [HandSetup.cs](../範例程式/U3/HandSetup.cs)，同樣掛在 DesktopLab 物件。
4. 依表填 HandSetup；只允許 Ready 階段選手，遊玩中不切換。

| HandSetup 欄位 | 拖入 |
| --- | --- |
| Lab／Catcher Root | DesktopLab／CatcherRoot。 |
| Left Controller／Right Controller | Rig 裡對應控制器。 |
| Left UI Ray／Right UI Ray | 選對應 Ray Interactor 物件，從 Inspector 拖 **Ray Interactor 元件標題**進欄位，不拖整個控制器。 |
| Haptics／Panel | CaptureHaptics 元件／ScreenCanvas 的 LabPanel。 |

在 MainPage 建兩個 UI Button：LEFT／RIGHT，Pos X 分別 -130／130、Y -45、Size 230×55。On Click 拖 DesktopLab，分別選 HandSetup.SelectLeft()／SelectRight()；選手後再從電腦按開始。

- 若先測右手，Left Hand 不勾；測左手時由 HandSetup 切換震動手別。
- 左右手選擇會搬動捕捉器與螢幕，改由另一手點 UI；不交換追蹤座標。
- 模擬器不會讓實體控制器震動；借到 Quest 才驗收觸覺。

## 8. 做第一段修復動畫

| 步驟 | 操作 | 設定 |
| --- | --- | --- |
| 1 | Hierarchy 建空物件 `RepairDemo` | 世界 Position `(-2.5, 0, 2.5)`。 |
| 2 | 其下建 Cube `CityBlock` | Local Position `(0, 0.1, 0)`、Scale `(1, 0.2, 1)`。 |
| 3 | 選 RepairDemo → Window → Animation → Animation | 按 Create，存 `Art/Animations/Repair.anim`。 |
| 4 | 按 Animation 視窗紅色 Record | 時間線在第 0 秒，先記錄 CityBlock Position／Scale。 |
| 5 | 時間線移至第 3 秒 | CityBlock Local Position 改 `(0, 1, 0)`、Scale `(1, 2, 1)`，形成修復升起。 |
| 6 | 關閉 Record，按 Animation 預覽播放 | 方塊從矮變高，底部留在地面。 |
| 7 | Project 選 Repair.anim | Inspector 取消 Loop Time；Animator 預設狀態名確認為 Repair。 |
| 8 | 複製 [RepairSequence.cs](../範例程式/U3/RepairSequence.cs)，掛到 RepairDemo | Lab 拖 DesktopLab；Animator 拖同物件自動建立的 Animator。 |
| 9 | Animation 時間線選最後一格 → Add Event | Inspector Function 選 FinishRepair。 |
| 10 | Play，正常走到回收確認 | 自動播 Repair；完成事件讓 Phase 進 Ending。 |

不再手按 Complete placeholder repair。正式轉化物品／城市修復可替換此動畫，保留完成事件入口。

## 9. 接正式開場與教學影片

先有美術提供的 Intro／Tutorial 兩段影片再做；缺素材時仍用U1佔位示範。

| 步驟 | 操作 | 設定 |
| --- | --- | --- |
| 1 | 兩段影片放 `Art/Video/` | Intro 約 15 秒；Tutorial 含操作動畫，發聲步驟只用字幕。 |
| 2 | Project 右鍵 Create → Rendering → Render Texture | 命名 DemoVideoRT，Size 1280×720。 |
| 3 | Hierarchy 建 Canvas `IntroCanvas` | World Space；世界 Position `(0,1.6,2)`、Rotation 0、Scale 0.001；Width 1280、Height 720。 |
| 4 | Canvas 下建 UI → Raw Image | 選全展開 Anchor，四邊 Offset 0；Texture 拖 DemoVideoRT；Raycast Target 關。 |
| 5 | DesktopLab 物件 Add Component → Video Player | Play On Awake／Loop 關；Render Mode 選 Render Texture；Target Texture 拖 DemoVideoRT。 |
| 6 | 有影片音軌時，加 AudioSource | Play On Awake 關；Video Player 的 Audio Output 選 Audio Source，指定此音源，讓聲音進 Unity 混音。 |
| 7 | 複製 [DemoVideoSequence.cs](../範例程式/U3/DemoVideoSequence.cs)，掛 DesktopLab | 依下表接參照。 |
| 8 | DesktopLab 的 Automatic Demos 取消勾選 | 由影片完成事件推進，不再用練習秒數推進。 |
| 9 | Play → Start intro | Intro 完整播放→Tutorial→Active；不用觀眾練習過關。 |

| DemoVideoSequence 欄位 | 拖入 |
| --- | --- |
| Lab／Video | DesktopLab／Video Player 元件。 |
| Intro Clip／Tutorial Clip | Project 中兩段匯入影片。 |
| Panel | IntroCanvas；腳本必須掛在 Canvas 外，才不會把自己停掉。 |

| 卡住時 | 檢查 |
| --- | --- |
| 影片黑畫面 | Render Texture 是否同時接到 VideoPlayer 與 RawImage？影片在兩台 OS 是否可播放？ |
| 播兩段時又提前進 Active | Automatic Demos 是否已取消？ |
| 播完不前進 | 兩段 Clip 是否填完整、Loop 是否關閉、目前是否暫停？ |
| 回收演出卡住 | Animation Event 是否加在 Repair.anim 最後一格？FinishRepair 接收元件是否掛在 Animator 同一物件？ |

## 10. 中文字型

1. 先用英文標籤確認功能；正式 UI 請美術提供可隨專案發布的 `.ttf`／`.otf`。
2. 匯入 `Art/Fonts/`；在 Project 選字型 → Create → TextMeshPro → Font Asset。
3. 將產生的 Font Asset 拖到 TMP 文字的 Font Asset 欄位。
4. 若採 Dynamic 字集，確認來源字型隨專案交付；用實際音虫名稱與回收字幕測缺字。
5. 中文方框／缺字警告要修字型字集，不靠放大文字解決。

## 11. 收藏卡片與成果使用同一份資料

| 步驟 | 操作 | 預期 |
| --- | --- | --- |
| 1 | DesktopLab 物件 Add Component → VariantCatalog | Entries Size 9；順序 A1、A2、A3、B1～C3。 |
| 2 | 各格填 Name／Source Label；Icon 拖對應圖像 | 圖像 Import Settings：Texture Type 選 Sprite (2D and UI)，Apply。 |
| 3 | DesktopLab 的 Catalog 拖 VariantCatalog | I1 產生的名稱／聲音來源與 UI 同源。 |
| 4 | 複製 [CollectionCard.cs](../範例程式/U3/CollectionCard.cs)，更新 LabPanel.cs | 放 Scripts/Tutorial；保留既有 .meta。 |
| 5 | CollectionPage 下建 UI Image，命名 Cards；加 Grid Layout Group | Cell Size 104×145、Spacing 7×7、Constraint Fixed Column Count 5；Rect 550×150。 |
| 6 | Cards 下建 UI Image Card，尺寸 104×145 | 下建 Icon(Image，Y 30、80×65)、Title(TMP，Y -20、100×35)、Source(TMP，Y -60、100×45)。 |
| 7 | Card 加 CollectionCard，接 Icon／Title／Source | 文字關 Raycast Target；背景可保持。 |
| 8 | Card 拖到 Prefabs/UI/ 成為 Prefab，再刪場景中的 Card | Cards 留空，由收藏資料建立。 |
| 9 | LabPanel：Catalog 拖 VariantCatalog；Card Root 拖 Cards；Card Prefab 拖該 Prefab | 三欄填完整；原 CollectionText 保留作空集合提示。 |
| 10 | 收集兩個不同變體→收藏→回主畫面→重開收藏 | 兩張卡片各有圖像、名稱、來源；不多出群數或重複卡。 |

- 九個來源音檔的陣列順序沿用 U2；VariantCatalog 不另外播放音檔。
- 聲部交付後，在 VariantCatalog 填 BPM／Beats Per Bar／Bars。測試值為 100／4／4；正式值依聲音交付表填寫，I1 會一起存入固定成果。
- 素材未交付可先填 Sample A1／Source A1；交付後改同一份 Catalog，不改收集規則。
- I1／W1 的 image_id 對應 A1～C3；網頁圖放版本化 assets 的 images/，票面黑白圖另交 I2。

## 卡住時

| 現象 | 優先檢查 |
| --- | --- |
| 沒模擬器面板 | 樣本有 Import？場景只放一份？Game 視窗有焦點？ |
| 兩個相機或 AudioListener 警告 | 停用原場景相機，保留 Rig 內一套。 |
| 右手動但 Mask 不動 | Tracked Aim 是否拖成 AimOrigin？Use External Pose 是否勾選？ |
| 螢幕文字消失 | 停止 Play，確認 TMP Essentials、文字色與背景對比；先用英文標籤，中文字型見本包第 10 節。 |
| 有射線但按不到 | Event Camera、XR UI Input Module、Ray Interactor 的 UI Select、文字的 Raycast Target 是否擋住 Button。 |
| 回收不授權 | 確認 SAN 0、Station Zone 有拖、Tip 真正入區、頭戴在近距離且圈內。 |
| 面板 NullReference | LabPanel 七個參照是否填完整？不要把 `.cs` 資產拖入 Lab 欄位。 |
