## 1. 裝套件與匯入樣本

| 1 | Package Manager → `+` → Install package by name | 安裝下表固定版本。 |
| 2 | 選 XR Interaction Toolkit → Samples | Starter Assets、XR Interaction Simulator 分別按 Import；不選 Legacy。 |
| 3 | Project 的 Assets/Samples 展開 | 找到 XRI／3.3.2 下匯入的資料夾。 |

## 2. 放入一套 Rig

1. 停用原場景 Main Camera；不要停用稍後匯入 Rig 內的相機。
2. Project 搜尋 `XR Origin (XR Rig)`，拖一份 Prefab 到 Hierarchy。
3. 搜尋 `XR Interaction Simulator`，拖一份 Prefab 到 Hierarchy。
4. 選 XR Origin，世界 Position／Rotation 0、Scale 1。
5. 展開 XR Origin：保留 Camera Offset、Main Camera、Left Controller、Right Controller。
6. 在 Locomotion 保留 XRI 的移動元件，Move Action 接左手搖桿；停用 Teleportation 和 Turn。將 Move Provider 元件拖入 DesktopLab 的 XR Move Provider，讓階段與追蹤狀態控制移動。用搖桿確認平移 XR Origin，實體原地轉身。
7. Play，確認模擬器有操作面板；按 Tab 切換模式、`[`／`]` 切左右控制器，其他鍵看面板標示。
8. 確認頭手可動後停止 Play。

| 檢查 | 要看到什麼 |
| --- | --- |
| 相機／AudioListener | 只有 Rig 裡一套啟用。 |
| Input Action Manager | Actions 清單有 Starter Assets 的 `XRI Default Input Actions`；空白才補拖。 |
| 模擬器 | 本章手動放 Prefab，不再勾另一份自動加入。 |
| 地面高度 | 模擬頭部約在地面上 1.6 m；高度由模擬器輸入調整，不放大 XR Origin。 |

## 3. 建捕捉器

在右控制器下建立以下階層；先用 Cube 暫代美術模型。

```text
Right Controller
  CatcherRoot
    Model
    AimOrigin
    Tip
    ScreenCanvas（下一節建立）
```

| 物件 | Local Position | Local Rotation | Local Scale／其他 |
| --- | --- | --- | --- |
| CatcherRoot | 0, 0, 0 | 0, 0, 0 | 1, 1, 1。 |
| Model（Cube） | 0, 0, 0.07 | 0, 0, 0 | 0.12, 0.08, 0.18；移除 Box Collider。 |
| AimOrigin（空物件） | 0, 0, 0.18 | 0, 0, 0 | Z 軸朝裝置前方。 |
| Tip（空物件） | 0, 0, 0.18 | 0, 0, 0 | 供近距離到站使用。 |

DesktopLab 欄位：

| 欄位 | 從 Hierarchy 拖入／設定 |
| --- | --- |
| Use External Pose | 勾選。 |
| Tracked Head | XR Origin → Camera Offset → Main Camera。 |
| Tracked Aim | AimOrigin。 |
| Tracked Tip | Tip。 |
| Show Developer Panel | 先勾；工作人員在電腦按 Enter 開場、暫代修復完成。正式觀眾畫面不放開始按鈕。 |
| Pose Valid | 模擬測試先勾；此欄位不是正式追蹤保護實作。 |

**檢查：** Play 後用模擬器移動右手，Mask 跟手而非頭部；不再用U1滑鼠視角當瞄準。

### 接入正式捕捉器模型

先完成第 4、5 節的螢幕和欄位接線，再換正式模型。

1. 停止 **Play**。把 FBX、貼圖放到 `Assets/_Project/Art/Catcher/`。將 FBX 從 **Project** 拖到 **Hierarchy** 的 `CatcherRoot` 下，替換 `Model` 的 Cube。比對握持大小和方向，在 **Inspector → Transform** 調整模型子物件，替換後移除 Cube。
2. 保留 `CatcherRoot`、`AimOrigin`、`Tip` 和已接線的 `ScreenCanvas`。移動 `AimOrigin` 到射線出口，轉到藍色 Z 軸朝前；把 `Tip` 放到實際插入站體的前端。把 `ScreenCanvas` 對齊模型的螢幕面。確認 **DesktopLab → Tracked Aim／Tracked Tip** 仍引用這兩個掛點。讓捕捉器外殼保持無 Collider，避免擋住自己的射線。
3. 將調整好的 `CatcherRoot` 從 **Hierarchy** 拖到 **Project** 的 `Assets/_Project/Prefabs/Catcher/` 存成 Prefab，保留原場景物件供控制器與 UI 接線。若在別的 Scene 放入新實例，重新指定該 Scene 的掛點和 UI 引用。
4. 用模擬器 **Play**。轉動控制器，確認 Mask 從捕捉器前方移動、瞄準能捕捉，螢幕按鈕可操作。再用左搖桿走一段，到站時依第 6 節驗證 `Tip`。

## 4. 建 World Space UI

首版直接顯示 SAN（原型暫用）、捕捉進度與目前目標名稱／編號。不設玩家開始選單；捕捉器按鈕只做外觀，仍是對準累積 3 秒自動捕捉，也不做失敗次數彈窗。以下也提供收藏分頁的預留接法；首版可保留欄位供自測，將該分頁與切頁按鈕隱藏。

1. GameObject → XR → UI Canvas；命名 `ScreenCanvas`。
2. 拖到 CatcherRoot 下；保留工具建立的 XR UI EventSystem。
3. Canvas Render Mode 確認 World Space；Event Camera 拖 Rig 的 Main Camera。
4. Rect Transform Width `600`、Height `400`；Local Scale 三軸 `0.0003`。
5. Local Position `(0, 0.07, 0.09)`、Rotation `(60, 0, 0)`，先得到約 18×12 cm 螢幕。
6. Canvas 加 Image 作底色，勾 Raycast Target；加入下表階層。
7. 首次建立 TMP 文字若要求匯入資源，按 Import TMP Essentials。
8. 複製 [LabPanel.cs](../範例程式/U3/LabPanel.cs)及 [CollectionCard.cs](../範例程式/U3/CollectionCard.cs)到 Scripts/Tutorial；LabPanel 掛在 ScreenCanvas。

```text
ScreenCanvas（Canvas、Image、LabPanel）
  StatusText（UI → Text - TextMeshPro）
  MainButton（UI → Button - TextMeshPro）
  CollectionButton（UI → Button - TextMeshPro）
  MainPage（空 UI RectTransform）
    HintText
  CollectionPage（空 UI RectTransform）
    CollectionText
  RecyclePage（空 UI RectTransform）
    ConfirmButton
```

建三個 Page：在 Canvas 下用 UI → Image 建立並改名，再 Remove Component 移除 Image，保留 RectTransform。

| UI 物件 | Pos X／Y | Width／Height | 內容 |
| --- | --- | --- | --- |
| StatusText | 0／135 | 560／110 | 字級 26；先填 SAN。 |
| MainButton | -145／40 | 270／55 | HOME。 |
| CollectionButton | 145／40 | 270／55 | COLLECTION。 |
| 三個 Page | 0／-95 | 560／170 | Anchor／Pivot 均為中心；只有一頁顯示。 |
| HintText | 0／0（相對 MainPage） | 540／150 | LISTEN, AIM。 |
| CollectionText | 0／0（相對 CollectionPage） | 540／150 | 字級 24，靠左上。 |
| ConfirmButton | 0／0（相對 RecyclePage） | 400／65 | CONFIRM RECYCLE。 |

所有 TMP 文字先取消 Raycast Target，讓 Button 底圖接收點擊；Canvas 底圖維持勾選以偵測 UI hover。

## 5. 接欄位與按鈕

| ScreenCanvas 的 LabPanel 欄位 | 拖入 |
| --- | --- |
| Lab | DesktopLab 物件。 |
| Status Text／Main Page／Recycle Page | 拖入 StatusText、MainPage、RecyclePage。 |
| Enable Collection Preview／Collection Text／Collection Page | 首版維持關閉，兩個欄位可留空。做收藏分頁時再勾選及接線。 |
| Confirm Button | RecyclePage 裡的 ConfirmButton。 |

依[共用按鈕接法](../Unity基本操作.md#接-buttonunityevent)設定：

| Button | 接收物件 | On Click 方法 |
| --- | --- | --- |
| MainButton | ScreenCanvas | LabPanel → ShowMain()。 |
| CollectionButton | ScreenCanvas | LabPanel → ShowCollection()。 |
| ConfirmButton | ScreenCanvas | LabPanel → ConfirmRecycle()。 |

- 選 EventSystem：只啟用 XR UI Input Module，不能同時留另一個輸入模組。
- 選左手 Ray Interactor：開 UI Interaction；UI Select 使用 Starter Assets 綁定。
- 此時右手持捕捉器、左手指向螢幕按扳機；滑鼠不是正式介面操作。
- LabPanel 自動在 UI hover 時阻擋捕捉並收 Mask，移開後恢復；不用另外手動勾 UI Busy。

### 換上正式介面素材

1. 停止 Play。把主畫面、回收頁、按鈕與圖示的分層 PNG 放到 Assets/_Project/Art/UI。選 PNG → Inspector → **Texture Type → Sprite (2D and UI) → Apply**。
2. 在 ScreenCanvas 或 RecyclePage 選對應的 Image，改 **Source Image**。裝飾圖新增為 UI → Image，調整 Rect Transform；取消裝飾圖的 Raycast Target，以免蓋住互動按鈕。
3. 保留 StatusText、ConfirmButton 及 LabPanel 接線。按鈕換圖時改原 ConfirmButton 的 Image；若美術有提供不同狀態圖，可在 Button → Transition 選 Sprite Swap，對應 Highlighted／Pressed／Disabled。文字換字體依第 10 節。
4. Play 驗證 SAN、目標與進度仍會更新。到站前不出現確認按鈕；到站後能用左手點選。測瞄過介面時捕捉暫停，移開後可接續。

### 捕捉成功預覽

1. 把 [CaptureModelPreview.cs](../範例程式/U3/CaptureModelPreview.cs) 放進 `Assets/_Project/Scripts/Tutorial/`。將它掛在一直啟用的捕捉器介面父物件。
2. 在 **Project → Create → Render Texture** 建 `CapturePreviewRT`。在捕捉器主畫面的 Canvas 內新增 **Raw Image**，Texture 指向該資產。
3. 新增 `CapturePreviewStage`、空物件 `PreviewModelRoot` 和 **Camera**，擺在城市可走區外。新增專用 Layer `CapturePreview`，設到 `PreviewModelRoot`。預覽 Camera **Culling Mask** 只勾這一層，遊戲相機取消這一層。預覽 Camera 的 **Target Texture** 指向 `CapturePreviewRT`，**Target Eye** 選 **None**，移除附帶的 **Audio Listener**。
4. 將預覽相機朝向 `PreviewModelRoot`，先用一隻測試模型確認構圖，再移除測試物件。螢幕版 Prefab 套美術給的精緻材質。若與場景版共用網格，把螢幕版材質指定在這個 Prefab 的 Renderer，並統一各款的構圖尺寸和中心。
5. 把 **Lab**、**Preview Camera**、**Display**、**Model Root** 拖到元件欄位。**Variant Models** 設 Size 10，依[變體表](../../開發規格.md#音虫與城市配置)接精細版 Prefab，Element 7／8 留空。**Seconds** 的原型起始值為 1.5 秒。
6. Play 捕捉一群。場景音虫退場，捕捉器螢幕上出現對應的精細模型。再抓不同一款、進回收及重開場次，確認預覽會替換或清除。

## 6. 換成自己建的回收站

| 步驟 | 操作 | 設定 |
| --- | --- | --- |
| 1 | Hierarchy 建空物件 `StationRoot` | 世界 Position `(0, 0.9, 14)`，Rotation 0、Scale 1。 |
| 2 | 其下建 Cube `Body` | Local Position 0、Scale `(0.6, 0.5, 0.3)`；保留 Collider。 |
| 3 | 其下建空物件 `VisitZone`，加 Box Collider | 勾 Is Trigger；Local Position `(0, 0, -0.22)`，Size `(0.6, 0.5, 0.4)`。 |
| 4 | DesktopLab → Station Anchor | 拖 StationRoot；不再另外產生練習站體。 |
| 5 | DesktopLab → Station Zone | 拖 VisitZone 的 Collider。 |
| 6 | Play，捕捉至少 1 群後，用左手搖桿走到街尾 | SAN 80 也能到站確認。 |
| 7 | 走近站體，把捕捉器 Tip 放進 VisitZone | 螢幕自動開 RecyclePage。 |
| 8 | 移開 Tip，以左手控制器點確認 | 進 Recycling；剩餘音虫與聲音退場，收藏保留，不重複登錄。 |
| 9 | 驗證修復完成後前往結尾區 | 接完第 8 節就自動推進。未接演出時，依左上提示按 Enter 模擬修復完成。 |

回收站在虛擬街尾。在左端玩家起點建立空物件 ExitAnchor，拖到 DesktopLab 的 Exit Anchor。正式追蹤區以 X1 校正後的本地追蹤座標判定。

### 接入正式回收站模型

1. 停止 **Play**。把 FBX、貼圖放到 `Assets/_Project/Art/Station/`。將 FBX 從 **Project** 拖到 **Hierarchy** 的 `StationRoot` 下，替換 `Body` 的 Cube。在 **Inspector → Transform** 調整模型子物件，使感應面朝玩家可接近的一側，再移除 Cube。
2. 保留 `StationRoot` 與 `VisitZone`。讓站體的阻擋表面保有實體 Collider；選 `VisitZone`，在 **Box Collider → Edit Collider** 調到感應面前方、`Tip` 可伸入的位置，保持 **Is Trigger** 勾選。確認 **DesktopLab → Station Anchor** 仍指向 `StationRoot`，**Station Zone** 指向 `VisitZone` 的 Box Collider。
3. 單一固定回收站可直接留在 Scene。若需要在多個 Scene 重用，將 `StationRoot` 拖到 **Project** 的 `Assets/_Project/Prefabs/Station/` 做成 Prefab，再把各 Scene 的實例接到 **Station Anchor／Station Zone**。
4. 用模擬器 **Play**。空收藏時不授權。捕捉 1 群後，遠距指向仍不授權；走近並讓 Tip 進入感應區，才顯示確認。移開 Tip 後可按確認。

## 8. 回收粒子與建物修復

[RepairSequence.cs](../範例程式/U3/RepairSequence.cs)、[ReturnToStartGuide.cs](../範例程式/U3/ReturnToStartGuide.cs) 與 [EndingSequence.cs](../範例程式/U3/EndingSequence.cs) 已放在 Unity 專案的 Assets/_Project/Scripts/Tutorial。新建專案才從範例複製到這個路徑。

### 8.1 美術未到，先做金色粒子

| 步驟 | Unity 操作 |
| --- | --- |
| 1 | 在灰盒建築破損處建立空物件 RepairDemo。Add Component → Repair Sequence，Lab 拖 DesktopLab。Animator 留空。 |
| 2 | 在 RepairDemo 下建 **GameObject → Effects → Particle System**，命名 RepairSparks。移到破損處。 |
| 3 | Particle System → Main：Looping、Play On Awake 關閉。Start Lifetime 可試 1.5 秒，Start Speed 1，Start Size 0.08，Start Color 選金色。Emission 整組關閉，由腳本發射。 |
| 4 | Repair Sequence → Repair Particles 拖 RepairSparks，Particles Per Capture = 12，Particle Only Seconds = 3。先按這個值測試。 |
| 5 | Play，捕捉 1 群後到站確認。檢查只發射一次約 12 顆，約 3 秒後進 ExitRoute。重跑 2 群，檢查約 24 顆。兩次都測回收時仍能移動。 |

### 8.2 接建物修復動畫

可先用下表的方塊練習。做過 8.1 就沿用 RepairDemo 與 Repair Sequence。

| 步驟 | 操作 | 設定 |
| --- | --- | --- |
| 1 | 選取既有 RepairDemo；沒有才建空物件 | 方塊例的世界 Position 可設 (-2.5, 0, 2.5)。 |
| 2 | 其下建 Cube `CityBlock` | Local Position `(0, 0.1, 0)`、Scale `(1, 0.2, 1)`。 |
| 3 | 選 RepairDemo → Window → Animation → Animation | 按 Create，存 `Art/Animations/Repair.anim`。 |
| 4 | 按 Animation 視窗紅色 Record | 時間線在第 0 秒，先記錄 CityBlock Position／Scale。 |
| 5 | 時間線移至第 3 秒 | CityBlock Local Position 改 `(0, 1, 0)`、Scale `(1, 2, 1)`，形成修復升起。 |
| 6 | 關閉 Record，按 Animation 預覽播放 | 方塊從矮變高，底部留在地面。 |
| 7 | Project 選 Repair.anim | Inspector 取消 Loop Time；Animator 預設狀態名確認為 Repair。 |
| 8 | 選 RepairDemo 的 [Repair Sequence](../範例程式/U3/RepairSequence.cs)；若未掛，Add Component 加入 | Lab 拖 DesktopLab；Animator 拖同物件自動建立的 Animator。 |
| 9 | Animation 時間線選最後一格 → Add Event | Inspector Function 選 FinishRepair。 |
| 10 | Play，正常走到回收確認 | 自動播 Repair；完成事件讓 Phase 進 ExitRoute。 |

### 換上正式修復素材

1. 依[美術交付規格](../共用/美術與聲音交付.md#3-城市修復動畫與金色粒子)取得建物、前後貼圖及時序。和 U2 確認由誰修改共用場景。定位既有建物與其 Collider，之後只替換或調整顯示物件。
2. 同一模型要切換外觀時，在有關建物父物件下放兩份顯示模型，分成 BrokenVisual 與 RepairedVisual。先分別在 **Renderer → Materials** 依材質槽指定破損／修復材質。兩個顯示物件上的 Collider 關閉，沿用父物件的場景碰撞。
3. 把 Repair Sequence 與 Animator 放在能控制上述顯示物件的共同父物件。選父物件開 Animation，建立正式 Repair Clip。在第 0 幀錄下 BrokenVisual 啟用、RepairedVisual 關閉；依時序在指定幀交換啟用狀態。若採 Shader 漸變，第 0 幀也要記錄完整破損時的參數，最後一幀記錄修復值。
4. 在 Animator 將 Repair 狀態的 **Motion** 換成正式 Clip，Clip 關閉 Loop Time，最後一幀加 **FinishRepair**。確認新父物件上的 Repair Sequence 已接 Lab、Animator 與 Repair Particles；移除舊方塊及它的演出元件，避免同時觸發兩次。
5. 將 RepairSparks 移到美術標示的破損位置。若有光點 PNG，建可用於粒子的透明材質，拖入 Particle System → **Renderer → Material**。保留由程式依實收量發射的接法。
6. Play 測回收只播一次，播放期間可移動，完成後才出現入口指引。完成換場後再確認破損外觀是否回到第 0 幀。

### 8.3 結尾定點淡黑與感謝信

#### 先接「返回起點」語音

| 步驟 | Hierarchy／Inspector 操作 |
| --- | --- |
| 1 | Hierarchy → Create Empty，命名 `ReturnGuide`；Add Component → Audio Source。Play On Awake／Loop 關閉，Spatial Blend = 0（2D），Volume = 0.8。 |
| 2 | 匯入語音 WAV 至 `Assets/_Project/Audio/Narration/ReturnToStart.wav`。內容提醒城市修復完成、請返回起點；沒有正式素材時先用組員錄音測接線。 |
| 3 | ReturnGuide → Add Component → Return To Start Guide。Lab 拖 DesktopLab 物件；Prompt Source 拖剛建的 Audio Source；Return Prompt 拖 WAV。不接 On Captured 或 On Rain Started。 |
| 4 | Play、至少捕捉 1 隻並回收。完成修復、進 ExitRoute 後語音只播一次，起點指引出現。修復前不播放，整場重開後才可再次播放。 |
| 5 | 語音中按 P，聲音及 90 秒計時應停住；再按 P 從原處接續，不重頭播放。追蹤失效或越界同樣暫停。 |
| 6 | 90 秒內回起點，或留在街尾等 90 秒。兩者都只進結尾一次；超時不瞬移。先照下表接好 EndingSequence 才會有正式淡黑；純桌面佔位版直接進 ThankYou。 |

90 秒由 `GameRules.ExitRouteSecondsLimit` 控制，從修復完成開始；不包含修復動畫，不是整場探索倒數，也不重新計算 SAN 或收藏。

#### 再接起點結尾、淡黑與開信

| 步驟 | Unity 操作 |
| --- | --- |
| 1 | Hierarchy → Create Empty，命名 ExitAnchor，設於左端玩家起點。<br>CaptureLab 預設 Position：`(0,0,0)`；自訂場景複製出生點 X／Z，Y 設地面高度。<br>已有的 ExitAnchor 也移回起點，拖到 DesktopLab → Exit Anchor。 |
| 1a | 在 ExitAnchor 同位置放指引物件，可用薄 Cylinder 並移除 Collider；接到下方 Exit Guide。<br>修復完成進 ExitRoute 後，水平距離 0.75 m 內才觸發結尾；開場不觸發。 |
| 2 | 用第 4 節的 XR UI Canvas 做法建 EndingCanvas，掛在 Main Camera 下。Render Mode 選 World Space，Event Camera 選 Main Camera。Canvas Rect 約 1000×700，Local Position (0, 0, 0.7)，Local Rotation (0, 0, 0)，Local Scale (0.002, 0.002, 0.002)。 |
| 3 | Canvas 下建 Blackout（UI → Image），Anchor 全展開、四邊 Offset = 0、Color = 黑色且 Alpha = 1。取消 Image 的 Raycast Target，加 Canvas Group，Alpha = 0。 |
| 4 | 在 Hierarchy 將 LetterPanel 排在 Blackout 下方，兩者同層。LetterPanel 可用 UI → Image，設置中央約 600×400。其下建 OpenButton、FinishButton（UI → Button - TextMeshPro）和 LetterBody（TMP 文字）。按鈕先放在下方，正文放中央。按鈕文字設為 OPEN／FINISH；尚無中文字型時，第 5 步的三版正文先改英文。 |
| 5 | EndingCanvas 掛 [EndingSequence.cs](../範例程式/U3/EndingSequence.cs)。Lab 拖 DesktopLab；Blackout 拖 Blackout 的 Canvas Group；Letter Panel、Open Button、Finish Button、Body 各拖對應物件。Exit Guide 拖地標或留空。Letter Animator 留空。Fade Seconds 先用 1。 |
| 6 | OpenButton 的 **On Click → +** 拖 EndingCanvas，選 EndingSequence → OpenLetter()。FinishButton 同法選 EndingSequence → FinishLetter()。沿用 U3 的 XR UI EventSystem 和左手 UI 射線。桌面點不到時檢查 EventSystem 的輸入模組有啟用滑鼠。 |
| 7 | 回收後等修復結束，聽到語音後返回左端起點；或留在原位逛滿 90 秒。應淡黑並出現 OPEN。左手點開顯示對應正文，再按 FINISH 進 Ending。 |
| 8 | 收到美術完成的開信影格後，全部匯入 Unity 並把 Texture Type 設為 Sprite (2D and UI)。在 LetterPanel 下加 UI → Image，命名 LetterArt，將順序第一張填入 Source Image。 |
| 9 | 選 EndingCanvas，在 Animation 視窗建立 OpenLetter Clip。用 LetterArt 的 Image Sprite 軌依檔名順序放影格，Samples 設為美術交付的 FPS。停用 Loop Time，Animator 狀態命名 OpenLetter。 |
| 10 | 在動畫末端加 Animation Event → ShowLetterBody，把 EndingCanvas 的 Animator 拖到 Ending Sequence → Letter Animator。Play 後確認左手點選才播放、最後一格看得到、播完才顯示正文。 |

三版正文依實收 1／2～3／4～5 群選版。影片若之後交付，再另接素材路徑。現有程式狀態 EndingVideo 表示淡黑結尾段，這版由淡黑完成事件推進。

收到定稿正文後，在 **EndingCanvas → Ending Sequence → Letter One／Two／Three** 依序換成三版文字。不要把正文併進動畫圖。網頁也使用感謝信，用一場 1 群的結果及兩組其他分級樣本，對照 [W1 的網頁正文](W1.md#34-換上正式網頁素材)。

### 發聲教學（後續規劃，本階段先不做）

1. U2 的顯現測試通過後，在 Tutorial 示範循聲後補一行字幕，例如「轉向聲源，輕聲呼喚，看看附近有沒有回應」。字幕結束後，照原本的教學流程開始探索。
2. Tutorial 只播字幕及示意。進 Active 後才讓收音觸發既有群落顯現。用一次場景內提示帶入操作，再依實際收音狀態顯示提示。
3. 測觀眾全程不說話、照做呼喚、提早說話三種走法。都應完成教學，只有 Active 期間的有效發聲可讓群落回應。

## 10. 中文字型

1. 先用英文標籤確認功能；正式 UI 請美術提供可隨專案發布的 `.ttf`／`.otf`。
2. 匯入 `Art/Fonts/`；在 Project 選字型 → Create → TextMeshPro → Font Asset。
3. 將產生的 Font Asset 拖到 TMP 文字的 Font Asset 欄位。
4. 若採 Dynamic 字集，確認來源字型隨專案交付；用實際音虫名稱與回收字幕測缺字。
5. 中文方框／缺字警告要修字型字集，不靠放大文字解決。

- I1／W1 的 image_id 對應 A1～A3、B1～B4、C1；網頁圖放版本化 assets 的 images/，票面黑白圖另交 I2。

## 卡住時

| 現象 | 優先檢查 |
| --- | --- |
| 沒模擬器面板 | 樣本有 Import？場景只放一份？Game 視窗有焦點？ |
| 兩個相機或 AudioListener 警告 | 停用原場景相機，保留 Rig 內一套。 |
