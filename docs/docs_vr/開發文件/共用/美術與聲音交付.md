# 共用｜美術與聲音交付

素材格式、交付表與原型界線共用本頁；日期見[里程碑](../02_里程碑與美術期限.md)。模型匯入看 [U2](../工作包/U2.md)，修復／影片／字型看 [U3](../工作包/U3.md)。

## 1. 美術交付表

| 項目 | 格式／設定 | 技術收到後檢查 |
| --- | --- | --- |
| 模型 | FBX、貼圖、材質說明；公尺、Scale 1、明確 pivot | 匯入後與 1 m Cube 對照，不靠整個 XR Origin 縮放。 |
| 音虫 | 3 基礎外形×3 變體，名稱與資料表一致 | 9 個變體都有唯一 ID；同類可共骨架與動畫。 |
| 捕捉器 | 模型、握持方向、螢幕平面、前端標記 | 對齊控制器後，AimOrigin 與 Tip 正確。 |
| 回收站 | 模型、感應面、能量物品、修復前後狀態 | 圈內可伸手，無須真實外殼。 |
| 像素 UI | 主畫面／收藏／回收、分層圖及字型授權 | 在虛擬螢幕實際尺寸可讀，不只看平面圖。 |
| 收藏圖 | 彩色 PNG＋黑白版；每變體一張 | 不只靠顏色區分，紙票上也認得出。 |
| 教學 | 約 15 秒短版開場＋操作示範素材／字幕表 | 發聲步驟僅字幕，其他操作有動畫；不綁練習過關。 |

## 2. 音檔交付表

| 音檔 | 數量 | 規格 |
| --- | --- | --- |
| 音虫來源聲音 | 9 | 各變體不同；定位用 mono、乾淨起尾／循環，避免把方向感寫進 stereo。 |
| 旋律聲部 | 9 | 同 BPM、拍號、長度、共同起點及取樣率；無多餘前導靜音。 |
| 城市背景／回收／修復 | 按原型需要 | 不遮蓋循聲線索；捕捉器無發聲音效。 |

- 原型先交 WAV 主檔，技術依 Unity／網頁用途產出播放版本。
- 初次聲部交付可採共同 48 kHz、4/4；BPM 與小節數在音樂樣本交付時填入 catalog。JSON 範例數值不是正式配樂定案。
- 每次改音檔或配方需升素材版本，不覆寫已發布成果使用的舊檔。

## 本次原型採用界線

- 城市、音虫、捕捉器與回收站先完成可操作版本，再加細節。
- 開場以世界內面板／動畫及可自由轉頭的視角呈現，避免強制搬動頭部相機。
- 最終效能以 Quest Link 雙眼執行檔量測；桌面美觀不代表頭戴已通過。
