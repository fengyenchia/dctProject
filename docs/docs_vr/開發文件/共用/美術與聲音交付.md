# VR｜美術與聲音交付規格

[交付日期與對接工作包](../02_里程碑與美術期限.md#3-美術聲音交付期限) · [U2 場景、音虫與聲音](../工作包/U2.md) · [U3 捕捉器、修復與開信](../工作包/U3.md) · [W1 網頁](../工作包/W1.md) · [I2 紙票](../工作包/I2.md)

## 1. 每次交付要附的資料

- 美術組用 Blender 或原本的繪圖、剪輯工具製作並出檔。技術組負責 Unity 匯入、建 Prefab、接材質／動畫／粒子與互動事件，以及執行驗收。
- 每批附可編輯原檔、可匯入檔、預覽圖或短錄影，以及一份素材清單。原檔可依組內約定放共用空間。
- 檔名用固定素材 ID 或英文短名。角色、圖像、來源聲和聲部沿用同一個變體 ID，避免重新命名後對錯素材。
- 3D 模型以公尺為準，附正面、底面、中心或掛點示意。技術組匯入後用 1 m Cube 核對比例。
- 貼圖以 PNG 個別交付，檔名標用途，例如 City01_BaseColor.png、City01_Normal.png。材質卡列出貼圖對應的物件、材質槽、透明、發光等特殊設定。用節點產生的圖案若要在 Unity 重現，一併輸出所需貼圖。
- 使用外部素材或字型時，附來源及授權。

| 清單欄位 | 填寫範例 |
| --- | --- |
| 版本、日期、交付人 | alpha-01、交付日期、姓名 |
| ID、檔名、用途 | A1、A1.fbx、海天使變體 1 |
| 相依素材 | A1_BaseColor.png、A1_Source.wav、A1_Stem.wav、收藏圖 A1.png |
| 需對接的位置或事件 | 照射顯現、捕捉成功外觀、退場 |
| 已檢查、佔位、來源 | Blender 已核對尺寸；來源音暫用；自製或授權連結 |

## 2. 場景、音虫與道具

| 素材 | 美術交付 | 技術驗收 |
| --- | --- | --- |
| 街區與建物 | 建築 FBX、貼圖、俯視圖。標左端入口／結尾點、右端回收站、可進入房屋及門洞尺寸、室內可走範圍、音虫候選點與鐵皮屋。可進入的建物要有可用室內及真正留空的門洞。牆、門框、地面分件，或另附簡化碰撞示意。 | U2 對齊比例，設牆面碰撞與室內區域，測可循聲進屋。門外可聽見較小聲的室內音虫，瞄得到也無法捕捉。 |
| 雨景 | 美術組交一張雨景參考圖，標雨滴顏色、粗細與密度。有自訂雨滴圖樣時附透明 PNG。 | U2 在 Unity 建粒子、接材質，核對長街覆蓋範圍。 |
| 音虫模型 | 海天使 A、海兔 B、魟魚 C 各三款。附 A1～C3 對照圖、名稱、來源與單隻模型。交照射時的灰模與成功時的正式外觀，可用同一網格換材質。若有骨架，註明哪些變體共用。 | U2 用單隻模型複用成群。照射時按進度漸顯，成功結算後短暫顯示正式外觀再退場。 |
| 音虫動作 | 漂浮、吸收等模型動作交 Blender 原檔與含動畫的 FBX，附動作名、秒數、是否循環及觸發時點。純特效可交分層素材與短預覽。 | U2／U3 匯入動畫或重現特效。漂浮可循環，吸收在成功捕捉後觸發。 |
| 捕捉器 | 模型、貼圖及尺寸圖。標右手握持點、前端朝向、照射出口 AimOrigin、到站前端 Tip、螢幕可用寬高及面向。掛點可放 FBX 空物件，或用有尺寸的圖標註。 | U3 對齊右手控制器，檢查 Mask 從前端出發、Tip 可入站，左手能點選介面。 |
| 回收站 | 模型、貼圖及站體尺寸。標玩家站位、感應面位置／朝向、捕捉器前端要能伸到的範圍，以及能量效果起點。 | U3 放感應區。角色靠近且 Tip 進入範圍後，才開放左手確認。 |

## 3. 城市修復動畫與金色粒子

### 美術交付

- 交 .blend 原檔、建物 FBX、修復前／後各一組材質設定與貼圖。逐一標出材質槽，如 Wall_A、Crack_A。
- 若裂痕依區域消褪，交對應的遮罩圖並註明黑白代表哪一側。有發光或變色時，附前後顏色、強度或參考截圖。
- 附短預覽與下列時序。例子可改成美術實際設定。若只有換材質，標出切換時點與前後外觀即可；若希望漸變，另外標出漸變區域和開始、結束時點。

| 時點（示意） | 需要標註的變化 |
| --- | --- |
| 0 秒 | 保持破損外觀，從回收確認開始。 |
| 0.6 秒 | 粒子覆蓋哪個部位，哪個材質槽開始變化。 |
| 3 秒 | 裂紋淡到何種程度、最後停在哪組材質。 |

**粒子交付。** 美術給金色光球參考圖、出現位置及預期方向。若有專用光點貼圖，一併交透明 PNG。

### 技術組接入 Unity

- 先匯入一棟測試建物，用美術的貼圖、遮罩和時間點重現材質切換或漸變。由 U3 建 Prefab 和 Animator，修復動畫只播一次，完成後開放入口定點。[Unity 材質匯入說明](https://docs.unity.com/en-us/engine/6000.0/manual/assets-and-media/asset-types/models/importing/fbximporter-materials)
- 由技術組建粒子系統，回收後依實收數發射。灰盒先測 1 群及多群，再對位正式建物。驗收修復期間可移動、新場恢復破損狀態。

## 4. UI、開信與紀念品

| 素材 | 美術交付 | 技術驗收 |
| --- | --- | --- |
| 捕捉器主畫面與回收 | 可編輯設計稿加分層 PNG。背景、圖示、按鈕拆成獨立圖。標螢幕設計尺寸，文字保留可編輯。主畫面預留 SAN、當前目標、捕捉進度。另標到站前的提示及到站後出現的確認按鈕。收藏頁列後續。 | U3 在虛擬螢幕尺寸測字級，實際以左手點選確認。 |
| 感謝信及開信 | 美術組用熟悉的工具完成拆信動畫，交設計原檔、分層 PNG、透明背景的有序 PNG 影格（例如 LetterOpen_0001.png）、FPS 與短預覽。註明正文出現時點。企劃另交 1 群、2～3 群、4～5 群三版可編輯正文。 | U3 接入口淡黑，匯入並依 FPS 播放美術交付的影格，接左手點選與播完顯示正文。三版共用開信動作，VR 與網頁依同一分級顯示對應正文。 |
| 收藏圖 | A1～C3 各一張彩色及一張黑白 PNG，共 9 組。圖像留邊並在各自資料夾維持 ID，例如 color/A1.png、ticket/A1.png。 | W1 用彩色圖，I2 用黑白圖。抽查紙票尺寸下能分辨外形。 |
| 紙票與手機成果頁 | 紙票交黑白版型，預留 1～5 個實收圖、聲音名稱清單與 QR 空位。手機稿標圖、文字及播放按鈕狀態。 | I2 動態排圖與生成 QR，借到 80 mm 印表機後驗證可印範圍。W1 測手機素材可讀。 |
| 開場與操作教學 | 觀眾螢幕前導、頭戴內約 15 秒短版、循聲／照射／捕捉／回收示範。若交影片，用 MP4 並附可編輯字幕或時間碼表。 | U3 分段接入，核對字幕與操作示範時序。 |

## 5. 音檔交付

| 音檔 | 數量與格式 | 補充資料 |
| --- | --- | --- |
| 音虫來源聲 | 9 個 WAV，單聲道。示例 A1_Source.wav。 | 個別交循環起訖。音檔保留乾淨聲源，方向、室內外衰減及捕捉降音由 Unity 設定。 |
| 紀念品旋律聲部 | 9 個 WAV。示例 A1_Stem.wav。 | 同 BPM、拍號、取樣率、樣本起點及總長，從同一時間匯出，保留必要休止。附 BPM、小節數及各檔的變體 ID。 |
| 雨打鐵皮 | 美術／聲音組交 1 段可無縫循環的 48 kHz WAV。檔名可用 `RoofRain_Loop.wav`。 | 單獨交檔，附來源與授權。循環接點應無空拍或爆音。探索滿 60 秒後由 U2 在 Unity 播放及混音，驗證雨聲下仍可分辨魟魚聲源方向。 |
| 其他環境與演出聲 | 城市背景、回收與修復依場景分軌。 | 標用途、是否循環及觸發時點。 |

原型主檔先用 WAV，可從 48 kHz 對齊。技術依 Unity 與網頁產生播放版。已發佈的紀念品使用原素材版本，任何音檔或聲部變更都升素材版本。

## 6. 交付前一起驗收

- 美術先交一棟建物的破損／修復前後預覽、一個測試變體與一個聲部。技術驗證進屋、捕捉成功外觀、修復觸發及開信時序，再匯入其他素材。
- 同時交一組 A1～C3 的對照表。技術對照模型、音檔、網頁圖及票面圖是否對到同一變體。
- 最後以 Quest Link 驗收雙眼材質、介面可讀、室內聲音和粒子效能。詳細步驟見[整合與驗收](整合與驗收.md)。
