## 2. 每次合併

**功能分支接入最新 main → 解衝突 → Unity 自測 → 合併 main → 再驗證 → Push**

- 同時只由一人整合；Git 無衝突仍要測 Unity，並記錄版本、系統、素材與結果。
- 其他兩台關閉 Unity、切 main → Pull，再開專案複驗。
- 詳細按鈕與衝突處理見[合併操作](../環境與Git.md#開分支與提交)。

## 3. 桌面原型檢查表

發聲顯現及 AEC／VAD 保留為後續規劃，這輪先不驗收。

| 測試 | 操作 | 通過標準 |
| --- | --- | --- |
| 開場 | Intro→Tutorial→正式開始 | 約 15 秒開場；看示範即可；SAN 100、空收藏。 |
| 群落 | 連續檢查開場與前 4 次捕捉後 | 預設開場屋內／屋外各 1 群。最多 2 群，天氣池還有可用變體時捕捉 1 補 1。 |
| 捕捉 | 先對準 1 秒，移開，再 2 秒 | 同群累積 3 秒完成；只結算一次。 |
| Mask | 照牆、對準懸空群落、瞄空處、指向 UI | 前兩者顯示光罩，瞄空處與 UI 接管時收起。只有有效對準才計捕捉進度。 |
| 室內音虫 | 從屋外隔牆聽、在空門洞外瞄準，再走進屋內 | 屋外仍能循聲且較小聲，隔牆較悶。門外照到也不計秒。進屋後聲音平滑恢復，可捕捉。 |
| U2 頭戴驗收（X1 協助） | 戴 Quest 核對左右眼顯示與遊戲聲源 | 貼圖、透明度、Mask 與循聲正常。 |
| 顯現基準 | 進度 40%後移開 | 仍顯現 40%。 |
| 聲音 | 同群捕捉至 50%，移開再繼續 | 音量係數保留 0.5，成功停聲；其他群不變。 |
| SAN | 成功 5 次 | 100→80→60→40→20→0，進 Return 並停止補群。 |
| 到站 | 遠距指向，再靠近／Tip 入區 | 遠距不授權；近距授權後移開仍能確認。 |
| 重複確認 | 連點回收或重送事件 | 只登錄、修復及產生成果一次。 |
| 提前回收 | 收集 1 群後確認 | SAN 80 仍可回收，場上群落、聲源與進度清除，收藏保留。 |
| 下雨 | 累計 180 秒／提前確認回收 | 探索中 A／B 退場、C 出現，收藏與 SAN 保留。提前回收則不觸發。 |
| 修復與結尾 | 回收後移動觀看，再回左端定點 | 粒子量隨實收；修復完成後入口定點才啟用。走入觸發淡黑一次。左手開信，影格播完才顯示正文；按 FINISH 後固定成果。 |
| 保存 | 同成果送兩次，再重開 Gateway | 相同結果與 token；results/outbox/自動列印各一筆。 |
| 斷網 | 關閉網際網路，完成一場 | 可本機保存與出圖；復線後補傳相同成果。 |
| 紀念品 | 開同網址兩次 | 相同變體、對應聲部、感謝信與素材版本。 |
| 下一場 | 保存／結尾／交票完成後重置 | 清本場狀態，保留成果、outbox、列印工作；QR 僅在紙票上，不等待掃碼。 |
