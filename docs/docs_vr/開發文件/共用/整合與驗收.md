## 2. 每次合併

1. 提交修改、關閉 Unity，留在功能分支；Fetch 後 Merge `origin/main`。
2. 確認沒有未解決衝突；Scene／Prefab 衝突找該資產主責處理，不直接整份覆蓋。
3. 開 Unity，Console 開啟 Error Pause；先測該包場景，再接入 Integration 跑共用流程。
4. 記錄版本、系統、素材與結果；有錯誤在功能分支修正，不推送 main。
5. 當次由一人切 main、Pull，再 Merge 已驗證的功能分支；若 main 有新提交，先回功能分支重新整合及測試。
6. 在本機 main 再開 Unity 複驗；成功後關閉 Unity，檢查必要提交，再 Push main。
7. 其他兩台關閉 Unity、切 main →「… → Pull」，再開專案複驗；不只用作者原機器驗收。

圖形介面逐步操作見[本機合併與檢查](../環境與Git.md#開分支與提交)。

## 3. 桌面原型檢查表

| 測試 | 操作 | 通過標準 |
| --- | --- | --- |
| 開場 | Intro→Tutorial→正式開始 | 約 15 秒開場；看示範即可；SAN 100、空收藏。 |
| 群落 | 連續檢查開場與前 4 次捕捉後 | 同時最多 3 群，捕捉 1 補 1；新變體不重複。 |
| 捕捉 | 先對準 1 秒，移開，再 2 秒 | 同群累積 3 秒完成；只結算一次。 |
| Mask | 照一般表面、UI、無表面 | 表面可顯示；UI 接管／無命中時收起；不誤算捕捉。 |
| 發聲顯現 | 用實際音訊或明確標示的除錯事件 | 前方多群 3 秒淡入＋1 秒淡出；無進度再隱藏。 |
| 顯現基準 | 進度 40%後移開 | 仍顯現 40%；發聲效果消退後回到此基準。 |
| 聲音 | 同群捕捉至 50%，移開再繼續 | 音量係數保留 0.5，成功停聲；其他群不變。 |
| SAN | 成功 5 次 | 100→80→60→40→20→0，進 Return；不補第 8 群。 |
| 到站 | 遠距指向，再靠近／Tip 入區 | 遠距不授權；近距授權後移開仍能確認。 |
| 重複確認 | 連點回收或重送事件 | 只登錄、修復及產生成果一次。 |
| 回收退場 | SAN 0 後確認回收 | 清除剩餘 2 群及其聲音；已收集 5 個變體保留。 |
| 保存 | 同成果送兩次，再重開 Gateway | 相同結果與 token；results/outbox/自動列印各一筆。 |
| 斷網 | 關閉網際網路，完成一場 | 可本機保存與出圖；復線後補傳相同成果。 |
| 紀念品 | 開同網址兩次 | 相同 5 變體、5 聲部與素材版本。 |
| 下一場 | 保存／結尾／交票完成後重置 | 清本場狀態，保留成果、outbox、列印工作；QR 僅在紙票上，不等待掃碼。 |
