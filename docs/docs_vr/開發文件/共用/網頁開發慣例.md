# 共用｜網頁開發慣例

依組內提供的[目錄截圖](../../assets/參考/網頁目錄慣例_2026-11-08.png)與[套件截圖](../../assets/參考/網頁套件慣例_2026-11-08.png)取用；不預建用不到的目錄。

- `web/` 與 `unity-vr/`、`gateway/` 同層，使用同一個 Git repo。
- web 使用 **pnpm 11.8.0**；提交 `package.json` 與 `pnpm-lock.yaml`。
- 網頁命令在 web 執行；建立／安裝／啟動見[W1](../工作包/W1.md#1-建立一次網頁專案)。

## 目錄：相對於 `web/`

| 目錄 | 本作品用途 |
| --- | --- |
| `app/` | App Router 頁面與 Route Handlers。 |
| `app/**/_components/` | 僅供該頁使用的元件。 |
| `components/ui/` | shadcn/ui 基礎元件。 |
| `components/common/` | 跨頁共用版面與狀態元件。 |
| `components/features/` | 旋律播放、成果摘要、場次狀態等可重用功能。 |
| `context/` | 確實需要跨元件共享狀態時再加入。 |
| `hooks/` | Gateway 連線、音訊播放等自訂 Hook。 |
| `lib/api/` | Axios、HTTP 呼叫；各 API 請求／回應型別與對應函式放一起。 |
| `lib/utils.ts` | 共用工具函式。 |
| `types/` | 全域共用、非 API 型別。 |

## 套件與界線

| 用途 | 採用 |
| --- | --- |
| 樣式／圖示 | Tailwind CSS、`@tabler/icons-react`。 |
| UI | shadcn/ui；只加入真正使用的元件。 |
| HTTP | Client API 使用 Axios；Next.js Server 資料層可使用 fetch。WebSocket 使用原生瀏覽器 API。 |
| 音樂 | Web Audio API，共同時間軸啟動。 |
| 共用契約 | repo 的 `shared/`；不在各頁各自發明結果格式。 |
| 收音 | Unity 執行端處理；網頁不接原始觀眾錄音。 |
