# 共用｜網頁開發慣例

目錄與套件依本文件安排；元件按頁面分資料夾，不預建用不到的目錄。

- `web/` 與 `unity-vr/`、`gateway/` 同層，使用同一個 Git repo。
- web 使用 **pnpm 11.9.0**；提交 `package.json` 與 `pnpm-lock.yaml`。
- 網頁命令在 web 執行；建立／安裝／啟動見[W1](../工作包/W1.md#1-建立一次網頁專案)。
- 頁面不顯示「示例、待補、待定稿」等開發提示；缺少的欄位先不顯示，保留必要的空資料與錯誤狀態。

## I1／W1 開工前環境

**對象：I1／W1 負責人，以及要在自己電腦執行 Web／Gateway 的成員。現在只準備 Unity 的人先略過。**

| 工具 | 固定版本 | 如何確認 |
| --- | --- | --- |
| Node.js | **24 LTS**；記錄建置時的完整版本 | `node --version`。 |
| pnpm | **11.9.0** | `pnpm --version`；已有此版本者不重裝。 |

尚未安裝者依 [Node.js 官方下載](https://nodejs.org/en/download)與 [pnpm 官方安裝指引](https://pnpm.io/installation)準備；pnpm 指定 **11.9.0**，不使用未指定版本的最新版指令。

| 資料夾 | 套件管理 | 提交檔案 | 其他成員初次安裝 |
| --- | --- | --- | --- |
| `web/` | pnpm 11.9.0 | package.json、pnpm-lock.yaml | 在 web 執行 `pnpm install --frozen-lockfile`。 |
| `gateway/` | pnpm 11.9.0 | package.json、pnpm-lock.yaml | 在 gateway 執行同一安裝指令。 |

兩個資料夾各自安裝與啟動，使用同一個 repo；目錄位置見[開發入口](../README.md#同一個-repo-的目錄)。

| 目錄 | 本作品用途 |
| --- | --- |

## 套件與界線

| 用途 | 採用 |
| --- | --- |
| 樣式／圖示 | Tailwind CSS、`@tabler/icons-react`。 |
| UI | shadcn/ui；只加入真正使用的元件。 |
| 動態 | Motion（`motion/react`）；共用動態與捲動互動優先使用。簡單 hover／顏色切換維持 CSS。 |
| HTTP | Client API 使用 Axios；Next.js Server 資料層可使用 fetch。WebSocket 使用原生瀏覽器 API。 |
| 音樂 | Web Audio API，共同時間軸啟動。 |
| 共用契約 | repo 的 `shared/`；不在各頁各自發明結果格式。 |
| 收音 | Unity 執行端處理；網頁不接原始觀眾錄音。 |

### 共用 UI 的實作位置

- Button、Avatar、Badge、Card、Pagination、Sheet：`web/components/ui/`，沿用 shadcn/ui 來源與 API；樣式接既有色彩變數，圖示用 Tabler。
- 成果清單每頁 12 張；只有一頁時隱藏分頁，超過一頁才顯示頁碼及 Previous／Next。
- 頁面功能元件從 `@/components/ui/...` 匯入，不在各功能元件重寫基本按鈕、頭像或標籤。
- 單一頁面的元件放 `components/<頁面>/`；至少兩個頁面使用才放 `components/common/`。不再集中到 `features/` 或分散到 `app/**/_components/`。
- Tailwind 透過 `web/postcss.config.mjs` 的 `@tailwindcss/postcss` 編譯，不再使用自訂 Turbopack CSS loader。
- 全站背景以 `background` 黑底為主，右上疊 `primary` 藍 18%、左下疊 `secondary` 紫 16% 的柔和光暈；沿用既有色彩變數。首頁主視覺區保持透明，讓漸層透出。
- Navbar 使用 `background` 30% 的半透明底與背景模糊，讓漸層自然透出。
- 圖示使用 `@tabler/icons-react`，不混用另一套圖示；播放器、漢堡選單、關閉與缺圖圖示已套用。
- `web/lib/utils.ts` 的 `cn()` 合併 class；`components.json` 指定元件目錄與 Tabler。
- 前端音檔請求在 `web/lib/api/audio.ts` 使用 Axios，保留 AbortSignal 取消功能；Server 成果讀取仍可使用 fetch。
- `SiteHeader.tsx` 的桌面／手機版共用 Motion 捲動動畫；往下捲向上隱藏、往上捲向下顯示。頂端、選單展開與鍵盤聚焦時顯示；觸控後保留的按鈕焦點不阻止動畫。減少動態設定下取消滑動過場。
- 分頁底線使用 Motion `layoutId` 在導覽連結間滑動，顏色沿用 `foreground`。
- 小於 64rem 時，Logo 與右上漢堡同列；點開 shadcn/ui Sheet，右半屏顯示四個分頁，左半屏加遮罩。使用 Motion 滑入／滑出，Tabler 漢堡與關閉圖示；選項點選、Esc、點左側遮罩或切回桌面時關閉，展開時鎖住背景捲動。
